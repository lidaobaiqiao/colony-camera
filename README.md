# 殖民地视角（Colony Camera）

**V1 初版 · 1.0.0，2026-10-04。** 镜头、选择和战略 UI 的首个完整开发里程碑已完成。

当前开发版本为 **1.5.1**：右键单击清空选区、拖动平移；修复寻路探查干扰执行路线，以及多工人清扫提前完成。相似选择替代原表面框选，单击沿 26 邻接扩展同类方块，默认最多 64 个；工具栏“上限”可修改并保存。立体选择、预设、投影和殖民地功能继续保留，旧归档保持原样。

从 MC 的自由建造开始，让玩家亲手设计预设，再用战略视角规划殖民地。当前实现 SLG 摄像机、方块选择、自定义预设、本地投影、打印工人、挖掘清扫、地面/仓储取料施工及工具生产。

**平台：Minecraft 1.20.1 · Forge 47.4.0 · Java 17。** 1.5.1 须在客户端和服务端同时安装相同版本，单人游戏的内置服务端也由同一 JAR 执行。mod id 为 `colonycamera`。工程保留在此目录，开发存档位于 `run/`，勿清理。

从 [V1 发布页](https://github.com/lidaobaiqiao/colony-camera/releases/tag/v1.0.0) 下载 JAR、校验和与构建验证记录；仓库为私有，需有访问权限。[版本说明](docs/releases/v1.0.0.md) 与 [整体检查记录](docs/validation/1.0.0.md) 记录范围和验证边界。

## 使用

安装发行 JAR 到测试实例的 `mods` 目录，进入世界。

战略界面使用深色半透明面板：左上角显示模式，左侧显示选区信息，底部提供相似、立体、追加、清空、保存预设、预设库、殖民地任务及相似选择上限工具。右上角提供角度锁定、帮助与返回；工具可直接点击，悬停显示说明及实际绑定。

镜头与选区操作说明在右上角 `?` 中；打开时暂停镜头操作和选高，点击 `×` 或面板外关闭，世界仍继续运行。面板区域不进行方块选择或镜头拖动，世界框选在面板上松开时取消；选高时进入面板暂停，离开后从当前鼠标位置继续。SLG 隐藏原版快捷栏、角色数值栏和药水图标，返回第一人称后恢复。

| 操作 | 功能 |
| --- | --- |
| F6（可在按键设置更改） | 第一人称 / SLG 切换 |
| F7（可在按键设置更改） | 锁定 / 解锁镜头角度 |
| 中键拖动 | 解锁后旋转镜头、调整俯角 |
| 右键单击 / 拖动 | 清空选区并取消未完成选择 / 平移镜头（拖动达到 4 个物理像素） |
| WASD | 按镜头朝向平移 |
| 空格 / C（可在按键设置更改） | 镜头上升 / 下降 |
| 左 Shift | 镜头加速 |
| 滚轮 | 始终缩放镜头，距离 8–96 格 |
| 鼠标悬停 | 白框显示镜头下鼠标指向的方块 |
| 左键单击 / 拖动 | 相似模式单击扩展同类相邻方块；立体模式拖底面、松开选高、再单击确认 |
| G（可在按键设置更改） | 开关追加选择，持续保留后续操作的并集 |
| V（可在按键设置更改） | 相似 / 立体模式切换 |
| Delete（可在按键设置更改） | 清空选择并取消未完成操作 |
| B / 底部保存按钮 | 保存已完成的选区为预设 |
| P / 底部预设库按钮 | 预设库、当前世界投影管理 |
| O / 底部殖民地任务按钮 | 挖掘、清扫、任务优先度、工具合成与殖民地科技 |
| R / M（投影调整中） | 旋转 90° / 镜像 |
| 方向键 / PgUp、PgDn（投影调整中） | 沿世界 X/Z 微调 / 调整高度 |
| F / Enter（投影调整中） | 重新跟随鼠标 / 确认保存投影 |
| Esc | 先关闭对话框或取消投影草稿，再返回第一人称 |
| F6（切换键） | 始终返回第一人称 |

进入时以角色位置为中心，默认 60° 俯角并锁定角度，鼠标自由显示。角度锁定仅禁止旋转，右键拖动、WASD 和滚轮继续可用。解锁后可用中键拖动改变朝向与俯角，俯角范围 15°–85°；重新锁定保持当前角度，退出后再次进入恢复默认角度和锁定状态。

升降沿世界 Y 轴改变镜头焦点高度，不改变俯角或缩放距离。锁定角度时也能升降，左 Shift 对键盘移动和升降均生效。键盘运动按每个渲染帧的实际时间更新，原有正常速度保持不变；窗口失焦后停止并清理时间基准。

SLG 模式隐藏本地角色身体、持物和角色位置上的火焰等视野遮罩，退出后恢复。角色实体仍在原位，世界继续运行，角色仍可能受伤或被推动；此效果不会赋予服务器隐身状态。

选中检测从摄像机按鼠标位置发射射线，允许选择镜头看到的已加载方块，边框跟随实际形状。默认相似模式，左键单击一个方块，以它为种子按广度优先扩展相同类型的相邻方块；上下、侧面、棱边和角点相接都算相邻，即周围 26 格。不同朝向、含水等状态仍按同一方块类型处理，不跨越不同类型或空隙。种子计入数量，默认每次最多 64 个。

底部“上限”打开设置弹窗，可输入 1–8192 并保存到游戏配置目录的 colonycamera-client.toml，重启后继续使用。达到上限即截断本次扩展并提示，不选整个连通片。空输入、0 或超过 8192 不能保存，取消/Esc 不修改设置；弹窗内键鼠不移动镜头、不选择世界，F6 仍可退出 SLG。黄框显示已提交选区，数量和状态在 HUD 中显示。

G 切换追加开关，开启后相似和立体选择均与已有选区合并并去重；关闭后下一次操作替换选区。相似选择上限约束单次点击，追加后的总量仍最多 8192。追加开启时点空处保留，关闭时点空处清空。

V 开启立体模式后，先在一个方块面上左键拖出底面，松开进入高度阶段；此时鼠标横向位置固定，上下移动鼠标调整沿这个面法线的层数，再左键点击确认。鼠标上移向命中面外侧延伸，下移向内部延伸，反向移动可减回底层。层数包含底面所在的一层，最少一层；从上表面开始，向外为世界 Y 轴向上，从下表面开始则相反，墙面对应横向厚度。底面保持固定，轴线的绿色方向为向外、红色方向为向内，黄色标记表示当前延伸位置。青色长方体预览包含全部格子，超范围显示红色；确认后选择其中所有非空气方块，包括被遮挡的内部。

高度阶段滚轮仍缩放镜头，不改变已经选好的层数。右键平移或解锁后的中键旋转会暂时释放鼠标横向限制并暂停高度调整；松开后从当前位置继续调整，不把镜头拖动的位移算进高度。键盘平移和升降也继续可用。高度灵敏度随当前镜头投影变化，缩放或镜头运动本身不会修改层数。

最多保留 8192 个方块；立体扫描范围最多 8192 格，范围中的空气也计入限额。超限、未加载、超过世界高度或世界边界时保留原选区。相似选择分帧扫描，每帧最多 2048 次世界查询、约 2 ms，并复查采样匹配和已查询区块，发现卸载或匹配变化则拒绝整次提交。立体扫描每帧最多 256 格、约 2 ms。固定面求交遇平行射线、镜头后方或超距离等无效交点时不能提交。这些软预算不代表实际 FPS 保证。

底面拖动中开始右键平移或解锁后的中键旋转会取消底面操作；高度阶段允许这些镜头操作。失焦或窗口缩放取消未完成操作，包括高度阶段，保留已有选择；退出 SLG 清理全部选择与模式。目标变为空气或区块卸载后，选择在后续分帧检查中清除。

新选择按键支持键盘或鼠标重绑定，提示显示实际绑定。选择本身只更新本地状态；O 面板下达任务后才由服务端安排工人执行，左键选择不会直接触发角色挖掘、放置或攻击。

当前采用透视投影，只覆盖角色附近已加载区域，尚无切层或远程加载。光影与其他摄像机模组兼容性待测。

## 自定义预设与投影

1. 在第一人称亲手搭建建筑，F6 进入 SLG，用 V 立体选区选中整个结构（相似选择只扩展同类方块，完整多材质建筑使用立体选择）。
2. 确认选区后按 B，输入名称并保存。P 打开预设库，可查看尺寸和方块清单、重命名或删除。
3. 选择预设并点击“加载投影”。鼠标指向已加载方块表面，左键固定位置；R/M 旋转与镜像，方向键调整 X/Z，PgUp/PgDn 调高度，滚轮仍缩放镜头。
4. Enter 或“确认”保存投影。P 的“当前世界投影”页可重新调整、显示/隐藏或移除，Esc 取消调整时保留原位置。
5. 退出 SLG、返回第一人称或重启游戏后，已确认投影仍可查看。青色为待建，红色为已有方块冲突，匹配的方块不重复绘制。

投影本身只显示规划；在“当前世界投影”页点击“创建工程”后，服务端才安排实际施工。仅保存方块状态，不保存容器物品、方块实体内部数据和实体；箱子、告示牌、液体等特殊渲染形状暂用占位轮廓，第三方动态模型/光影兼容待测。预设页的方块清单不是施工物品账单。

预设保存在游戏目录 `colonycamera/presets`，当前世界维度投影保存在 `colonycamera/projections` 下。每个预设最多 8192 方块、单边 256 格；每个世界维度最多 32 个投影、合计 32768 方块。缺失模组方块、损坏或未知版本文件不会静默替换，原文件保留。无需安装 Litematica 或 MaLiLib；此版不导入 `.litematic` 文件。具体格式、作用域和特殊模型边界见 [架构决策 0008](docs/decisions/0008-local-projections.md)。

## 打印工人与施工（1.3.0）

1. 保存并确认投影后，按 P →“当前世界投影”→选择投影→“创建工程”。工程默认优先度 5，可在 1–9 之间调整，数字越大越优先；同级按创建顺序分配工人和材料。
2. 在殖民地放置“打印核心”，周围留出实心地面与两格净空，右键打印工人；也可在 P →“工程”页点“打印工人”，从离当前工程最近的已加载自有核心打印。无工程时按角色位置选择核心。生成地点取决于核心，不要求角色站在工地或现成工人附近。
3. 在工人附近丢下对应建筑物品，或存入普通箱子、仓储箱及网络端口。工人扫描周围 24 格，确认可走到取料点和施工站位，领取真实物品并携带到工地施工。地面材料无需先入仓；上锁容器不供料。
4. 工程页显示进度、执行原因、发现的目标材料、预约数量和当前一步所需物品；发现数量不等于已经确认可达。调整优先度会重排未执行任务；缺料、支撑不足、路径不通、已有方块冲突和保护规则拒绝会等待重试，不清除现有建筑。
5. 可暂停、继续或取消工程；取消不回收已建方块，工人手中材料保留并可用于后续任务。已完成或取消的工程可移除记录。编辑、隐藏或删除本地投影不会修改已经创建的独立工程。

打印暂时免费，核心每秒可打印一名，每玩家每维度最多 8 名已加载工人。周围无安全站位、无自有核心、达到上限或没有权限时提示具体原因；尚无居民生活与打印经济。

施工区域须已加载、允许建造且在实际角色或自有已加载打印核心 128 格内。每玩家每维度最多 32 个工程、合计 32768 个预设方块；单次工程请求解压后最多 256 KiB UTF-8 JSON，压缩后最多 32000 字节；超过任一限额需拆分预设。工人只在已加载区块寻路，最长搜索距离 64 格；没有搭脚手架、挖路、远程区块加载或强制传送。

当前支持普通直接对应建筑物品的方块、成对的门与床、双层半砖。门和床每组消耗一件物品，双层半砖消耗两件。液体/含水状态、重力方块、双格植物、无法直接对应建筑物品的块暂拒绝创建工程。材料须为无额外 NBT 的匹配物品；箱子建成后为空，告示牌文字及其他内部数据不复制。特殊模组方块的放置回调和动态连接状态仍需单独适配。

工程与进度保存在服务端维度的 `data/colonycamera_construction.dat`（schemaVersion 1），工人归属与持料使用实体 NBT。未知或损坏工程格式进入只读保护并保留原数据。打印、仓储与网络边界见 [决策 0011](docs/decisions/0011-printing-core-and-storage.md)。

## 仓储与创造栏

创造模式物品栏的“殖民地”分页包含打印核心、仓储箱、容量升级件、堆叠升级件、存储网络控制器、端口和连接块，以及殖民地合成台与研究台；均有名称、模型、操作提示与生存配方，可在创造栏搜索中文名称。

生存模式使用原版工作台制作第一套设施：取得工作台解锁打印核心、殖民地合成台和研究台配方，取得箱子解锁仓储箱，铁锭解锁容量升级件，红石解锁堆叠升级件及网络控制器/端口，铜锭解锁连接块。材料不齐时关闭配方书的可合成筛选也能查看；已有存档可把相关材料取出再放回背包。完整材料与制作顺序见 [生存合成指南](docs/survival-crafting.md)。

| 物品 | 使用方式 |
| --- | --- |
| 殖民地仓储箱 | 右键查看按物品类型汇总的库存；初始 27 格，正常堆叠 |
| 仓储容量升级件 | 右键未上锁原版单箱，原地转换为 54 格仓储，保留物品、名称和朝向；双箱须先拆开。继续升级仓储至 81、108 格 |
| 仓储堆叠升级件 | 右键仓储，依次升至 2、4、8 倍；常规 64 堆叠物品最高每格 512 件，不可堆叠物品仍为 1 |
| 存储网络控制器 | 每个连通网络放一个 |
| 存储网络端口 | 右键统一存取网络内全部仓储物品；工人在可达端口领取材料 |
| 存储网络连接块 | 用相邻面连接仓储、控制器和端口；可沿地下布线 |
| 殖民地合成台 | 右键打开工具合成页；附近配置自有仓储或网络端口，工人到现场操作 |
| 殖民地研究台 | 右键打开科技页；使用附近殖民地库存支付研究材料并解锁下一阶段 |

持升级件 Shift + 右键仓储可拆除一级并返还升级件（创造模式不消耗/返还）；若容量缩减或堆叠降级会溢出则拒绝。菜单支持左/右键整组或部分存取、Shift 转移、分页和真实大数量显示，向背包或地面输出遵守物品原有堆叠上限；首版不支持拖拽分配和双击收集。仓储与端口提供 Forge 物品接口，可用漏斗存取。

网络节点必须同属一名玩家、位于已加载区域并以相邻面连通；上限 256 节点。多个端口共用同一库存和材料预约，端口不增加容量。物品始终保存在仓储箱，断连后不会消失，恢复连通即可再次通过端口取用。单箱即使接入网络也可手动管理自身库存，但工人经端口领取网络材料。

玩家、漏斗及明确下达的清扫任务负责入仓，工人按工程取料施工、按合成任务生产设施、升级件和工具。闲置全图整理、库存搜索、自动补库存/递归生产链、熔炼、能量/频道和跨维度网络尚未实现。无需安装投影、更多箱子、精妙背包或 AE 模组。

## 挖掘、清扫与殖民地生产（1.4.x）

1. F6 进入 SLG，单击相似选择不规则同类方块，或用 V 立体选择包含内部的体积。确认后按 O →“挖掘选区”。工人先取得合适工具，再走到可达站位开采；施工、挖掘、清扫、合成及研究共用 1–9 优先度，同级按创建顺序。
2. 在地面框选需要整理的区域，O →“清扫选区”。清扫范围取已选方块的包围盒并包含顶面上方一格，工人把其中可取用的掉落物真实搬进自有仓储或网络端口。普通原版箱子可供施工/工具取用，清扫目的地需使用殖民地仓储；封闭、满仓、断连或拾取冷却会等待，已拿到的物品留在主手。
3. 放置殖民地合成台，在台周围三格内放自有仓储或可达网络端口，保留工人站位和取用路线。右键台，或 O →“合成”选择台、配方和次数后提交。材料须先入这些库存；目前生产九种殖民地设施/升级件，以及木棍及四种材质的镐、斧、铲，共二十二种配方。设施/升级件无需殖民地科技，工具仍按科技解锁。次数是配方执行次数，例如木棍一次产出四根，网络连接块一次产出八个。
4. 放置研究台并按同样方式配置库存，右键台或 O →“科技”下达下一阶段研究。科技按玩家及维度保存，研究须消耗真实材料；解锁后殖民地可合成和使用对应材质工具。高等级外来工具也受科技约束，不能凭空得到工具。
5. O 的任务页查看进度、阻塞原因、工人挖掘等级与工具，并调整优先度、暂停/继续或取消。暂停/取消保留已经挖掉的方块、已完成产物及真实持料，不回填地形、不退还已消费的研究材料；已完成或取消记录可移除。

| 科技阶段 | 研究材料 | 基础研究耗时 | 解锁工具 |
| --- | --- | --- | --- |
| 木器（初始） | 无 | 无 | 木镐、木斧、木铲及木棍 |
| 石器 | 圆石 ×16 | 200 tick（正常 20 TPS 下 10 秒） | 石镐、石斧、石铲 |
| 铁器 | 铁锭 ×8、煤炭 ×8 | 400 tick（20 秒） | 铁镐、铁斧、铁铲 |
| 钻石 | 钻石 ×2、红石 ×16 | 600 tick（30 秒） | 钻石镐、钻石斧、钻石铲 |

以上为工人在台前持续操作所需时间，移动、缺料或服务器低 TPS 会增加实际等待。工人合成每次基础 60 tick（3 秒）。完成时才原子扣料和入库；材料不足、产物/配方余料放不下、库存变化或保护拒绝时不免费产出，也不丢料。

工人初始挖掘等级 1，成功开采一块获得 1 经验；累计 16/48/112/240 经验升至 2/3/4/5 级，每级增加 15% 开采速度。土和木等允许空手的块可徒手挖；石材需有效镐。铁矿等需石工具的方块至少等级 2，钻石矿等需铁工具的方块至少等级 3，黑曜石等需钻石工具的方块至少等级 4；同时检查实际工具是否能获得正确掉落。

挖掘按真实方块硬度与工具耗时，保留原版掉落、经验球、耐久和 Forge 挖掘保护。方块在任务受理后被替换或移除会跳过，避免破坏后来新建的内容；打印核心、工作站、容器等所有带方块实体的块需玩家手动拆除，不可破坏或含液体状态也不批量开采。工具保存在副手，施工与清扫持料保存在主手，损耗、附魔、名字与经验随实体保存。自然掉落继续遵守原版归属规则。

附加任务与科技分别保存为服务端维度 `data/colonycamera_work.dat`、`data/colonycamera_technology.dat`，均为 schemaVersion 1；不支持或损坏的数据只读保留。现阶段下达一次清扫只处理该区域已有可取用掉落，完成后新出现物品需重新下达；合成不会自动追踪材料来源、造前置工具或处理任意配方。实现取舍见 [决策 0012](docs/decisions/0012-colony-work-and-technology.md)。

## 开发

```powershell
# JAVA_HOME 指向 Java 17；也可加 -JavaHome '你的 JDK 17 目录'
.\scripts\build.ps1
.\scripts\run-client.ps1
```
