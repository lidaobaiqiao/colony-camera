# 殖民地视角（Colony Camera）

**V1 初版 · 1.0.0，2026-10-04。** 镜头、选择和战略 UI 的首个完整开发里程碑已完成。

从 MC 的自由建造开始，让玩家亲手设计预设，再用战略视角规划殖民地。当前实现可切换的 SLG 摄像机与方块选择，预设与施工仍在后续路线中。

**平台：Minecraft 1.20.1 · Forge 47.4.0 · Java 17。** 当前摄像机为客户端模组，mod id 为 `colonycamera`。工程保留在此目录，开发存档位于 `run/`，勿清理。

从 [V1 发布页](https://github.com/lidaobaiqiao/colony-camera/releases/tag/v1.0.0) 下载 JAR、校验和与构建验证记录；仓库为私有，需有访问权限。[版本说明](docs/releases/v1.0.0.md) 与 [整体检查记录](docs/validation/1.0.0.md) 记录范围和验证边界。

## 使用

安装发行 JAR 到测试实例的 `mods` 目录，进入世界。

战略界面使用深色半透明面板：左上角显示模式，左侧显示选区数量与单个方块信息，底部提供表面、立体、追加和清空工具，右上角提供角度锁定、帮助与返回。工具可直接点击，悬停显示说明及实际绑定；当前工具与追加开关用青绿色标记。底部短提示跟随选择阶段，长消息可悬停查看全文。

完整操作说明在右上角 `?` 中；打开时暂停镜头操作和选高，点击 `×` 或面板外关闭，世界仍继续运行。面板区域不进行方块选择或镜头拖动，世界框选在面板上松开时取消；选高时进入面板暂停，离开后从当前鼠标位置继续。SLG 隐藏原版快捷栏、角色数值栏和药水图标，返回第一人称后恢复。

| 操作 | 功能 |
| --- | --- |
| F6（可在按键设置更改） | 第一人称 / SLG 切换 |
| F7（可在按键设置更改） | 锁定 / 解锁镜头角度 |
| 中键拖动 | 解锁后旋转镜头、调整俯角 |
| 右键拖动 | 拖动画面 |
| WASD | 按镜头朝向平移 |
| 空格 / C（可在按键设置更改） | 镜头上升 / 下降 |
| 左 Shift | 镜头加速 |
| 滚轮 | 始终缩放镜头，距离 8–96 格 |
| 鼠标悬停 | 白框显示镜头下鼠标指向的方块 |
| 左键单击 / 拖动 | 松开后单选 / 沿起点方块面确定范围，每列选择最外侧表面方块 |
| G（可在按键设置更改） | 开关追加选择，持续保留后续操作的并集 |
| V（可在按键设置更改） | 切换立体模式：先拖底面，再选高度并左键确认 |
| Delete（可在按键设置更改） | 清空选择并取消未完成操作 |
| 切换键或 Esc | 返回第一人称 |

进入时以角色位置为中心，默认 60° 俯角并锁定角度，鼠标自由显示。角度锁定仅禁止旋转，右键拖动、WASD 和滚轮继续可用。解锁后可用中键拖动改变朝向与俯角，俯角范围 15°–85°；重新锁定保持当前角度，退出后再次进入恢复默认角度和锁定状态。

升降沿世界 Y 轴改变镜头焦点高度，不改变俯角或缩放距离。锁定角度时也能升降，左 Shift 对键盘移动和升降均生效。键盘运动按每个渲染帧的实际时间更新，原有正常速度保持不变；窗口失焦后停止并清理时间基准。

SLG 模式隐藏本地角色身体、持物和角色位置上的火焰等视野遮罩，退出后恢复。角色实体仍在原位，世界继续运行，角色仍可能受伤或被推动；此效果不会赋予服务器隐身状态。

选中检测从摄像机按鼠标位置发射射线，允许选择镜头看到的已加载方块，边框跟随方块实际形状。普通模式左键单击单选，拖动达到 4 个物理像素后改为面框选：鼠标按下时固定方块的实际命中面，沿面的两个方向确定格子范围。终点若命中实际方块，使用该方块在面内的坐标，避免高台或低谷在起点平面上产生透视偏移；鼠标指向空处时才与固定参考面求交。青色矩形仍贴在这个参考面上，台阶等命中面可以位于半格高度；实际待选表面另以蓝色轮廓分帧预览。

普通框选会沿命中面的法线方向检查每一列，只选最外侧的一个具有可选轮廓的方块，不再局限于起点所在层。上表面框选随地形高低选每列最上面的方块；从下表面开始则选最下面的方块。水等没有 OUTLINE 轮廓的目标略过，叠放方块的内部不会一并入选。四个墙面也按对应外侧选择，但横向搜索限于起点前后各 32 格内的连续已加载区域，各列使用同一个搜索窗口。拖动范围包含起点和终点格。黄框显示已选区，HUD 显示数量、模式、追加状态和计算提示；单选时显示名称与坐标。

G 切换追加开关，开启后单选、面框选和立体选择都与已有选区合并并去重；关闭后下一次操作替换选区。追加开启时点空处保留，关闭时点空处清空。

V 开启立体模式后，先在一个方块面上左键拖出底面，松开进入高度阶段；此时鼠标横向位置固定，上下移动鼠标调整沿这个面法线的层数，再左键点击确认。鼠标上移向命中面外侧延伸，下移向内部延伸，反向移动可减回底层。层数包含底面所在的一层，最少一层；从上表面开始，向外为世界 Y 轴向上，从下表面开始则相反，墙面对应横向厚度。底面保持固定，轴线的绿色方向为向外、红色方向为向内，黄色标记表示当前延伸位置。青色长方体预览包含全部格子，超范围显示红色；确认后选择其中所有非空气方块，包括被遮挡的内部。

高度阶段滚轮仍缩放镜头，不改变已经选好的层数。右键平移或解锁后的中键旋转会暂时释放鼠标横向限制并暂停高度调整；松开后从当前位置继续调整，不把镜头拖动的位移算进高度。键盘平移和升降也继续可用。高度灵敏度随当前镜头投影变化，缩放或镜头运动本身不会修改层数。

最多保留 8192 个方块；普通面框选最多覆盖 8192 列，立体扫描范围最多 8192 格，范围中的空气也计入限额。超限、覆盖范围含未加载区块、超过世界高度或世界边界时保留原选区；表面搜索所依赖的区块在作业期间卸载也会拒绝整次操作。框选不按屏幕像素采样；需要固定面求交时，平行射线、镜头后方交点或超距离等无效情况不能提交。表面扫描分帧执行，每帧最多 2048 项世界查询、约 2 ms；立体扫描仍为每帧最多 256 格、约 2 ms。表面预览未完成时可先显示部分，完成后显示全部；松开左键会重新查询当前世界，避免提交拖动期间已被新块覆盖的旧预览。墙面提交搜索窗口也在松开时重新冻结。这些软预算不能保证实际 FPS。

底面拖动中开始右键平移或解锁后的中键旋转会取消底面操作；高度阶段允许这些镜头操作。失焦或窗口缩放取消未完成操作，包括高度阶段，保留已有选择；退出 SLG 清理全部选择与模式。目标变为空气或区块卸载后，选择在后续分帧检查中清除。

新选择按键支持键盘或鼠标重绑定，提示显示实际绑定。所有选择只更新本地状态，不执行挖掘、放置或攻击。

当前采用透视投影，只覆盖角色附近已加载区域，尚无切层、远程加载、预设或自动施工。光影与其他摄像机模组兼容性待测。

## 开发

```powershell
# JAVA_HOME 指向 Java 17；也可加 -JavaHome '你的 JDK 17 目录'
.\scripts\build.ps1
.\scripts\run-client.ps1
```

构建脚本执行测试和最终 JAR 检查，归档到 `dist/<版本>/`，同时生成 SHA256 与验证记录。也可以直接用 `gradlew.bat build` 和 `gradlew.bat runClient`。CI 使用相同的构建脚本。第一次构建需要联网下载依赖。
