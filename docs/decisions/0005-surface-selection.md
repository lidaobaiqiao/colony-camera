# 0005：普通框选逐列跟随最外侧表面

- 日期：2026-10-04
- 状态：采用；替代 0004 的普通单层扫描，保留固定参考面与 V 高度阶段

## 背景

用户指出固定起点层无法识别上方或下方的实际方块，并明确普通框选应跟随表面高度，每列只选最外侧一个方块。起点面的二维范围仍有用，但最终成员不能局限在该层。同时按用户要求将镜头旋转改为按住中键，平移改为右键，F7 角度锁定保留。

## 决策

`FaceSelection` 继续保存实际起始命中面、面平面及拖动范围。普通终点命中实际块时取该块的两轴切向坐标，法线坐标仍保留锚点层；空处才回退固定面求交。这样高台/低谷的终点不会因投影到起点平面而错位；V 模式仍始终固定面求交。两条切向轴决定框选的列集合，每列沿面法线检查最外侧的非空 OUTLINE 方块，至多贡献一个成员。上表面取最高的可选方块，下表面取最低的可选方块，四个墙面取对应外侧的可选方块。空列和空轮廓液体不增加成员；叠放结构的内部不会随着表面一起入选。

纯 Java `SurfaceSelectionJob` 负责列遍历、按六个方向从外向内的采样、结果与失败状态。`Source` 适配实际世界，提供保守占用范围与单格样本；一次 `step` 至多调用一次世界接口，让控制器可在步骤之间执行分帧预算。世界查询留在客户端适配层，作业不引用 Minecraft 或 Forge。

上下表面搜索使用世界有效高度。UP 借助 WORLD_SURFACE 高度图取得保守起始上界，再按实际 OUTLINE 排除水等空轮廓目标；DOWN 从最低有效 Y 向上，可以跳过已知空区段。墙面搜索限制在起点法线坐标前后各 32 格，并与所有列共有的连续已加载窗口相交；遇未加载扩展边缘缩窗，不能穿过缺失区块找更远表面。

作业冻结搜索窗口与全部区块依赖。拖动预览是临时结果，松开左键必须新建表面作业，查询松开后的世界，墙面搜索窗口在此时重新冻结；不能复用旧预览直接提交，因为拖动期间其他玩家可能把顶块埋住或移除。框选范围本身未加载时立即拒绝；冻结后任意依赖卸载则整体失败，确认前再次复查，不提交部分列。Minecraft 1.20.1 该映射中 `ClientLevel.hasChunk` 恒为 true，因此使用 `level.getChunkSource().hasChunk` 检查真实客户端区块缓存。后续悬停、提交、预览与选中失效检查都应遵循同一加载定义。

普通范围最多 8192 列，含空列；保留的选区仍最多 8192 个成员。表面扫描每帧最多 2048 项/约 2 ms，列范围查询和采样都计入项数。蓝色实际表面预览分帧完成，早期可以显示已完成的部分，完成后显示全部；起点面上的四边矩形继续显示范围参考，不宣称整个表面都位于起点高度。

V 立体操作继续以固定底面加沿法线层数确定长方体，不自动随表面起伏。范围最多 8192 格、每帧最多扫描 256 格/约 2 ms，保留非空气成员及被遮挡的内部；不采用普通表面的空 OUTLINE 过滤。已选集合的日常失效检查也保留空气/卸载规则，不因目标变成空 OUTLINE 而自动移除。替换/追加仍原子提交，保存操作开始时的追加开关，串行队列顺序不变。镜头拖动、Delete、失焦、窗口缩放和退出时的取消规则保留，交换中键与右键后提示和文档同步更新。

## 取舍

这是一种面内范围加逐列外壳的选择，不是按当前画面可见性采样。UP 从地下起点开始也可能选择同列更高的结构；DOWN 类似地可能选择更低的结构。墙面使用有界窗口，避免横向遍历整片世界或请求远程区块；未加载边缘缩窗意味着结果只表达冻结的已加载窗口。

范围参考面和最终表面轮廓表达不同信息：前者说明列集合，后者说明将被选中的成员。实际成员的轮廓跟随 OUTLINE 形状，半砖、台阶和栅栏不会变成完整方块。预览和结果只用于本地选择，不赋予世界修改权限。

分帧预算限制查询数量并提供时间软上限，单次世界查询不可中断；高度图、缓存和跳空区段减少工作，但不能保证 FPS。构建及纯 Java 测试也不能代替真实 Minecraft 世界中的加载、查询与渲染验证。

## 验证

纯 Java 测试覆盖六方向最外侧选择、每列单成员、空列、保守范围、不可用样本、临时只读结果、分步预算及整数边界。Minecraft 高度图、空区段、墙面加载窗口和真实预览按 [0.1.8 回归清单](../testing.md#018-表面框选与中键旋转回归) 单独验收。
