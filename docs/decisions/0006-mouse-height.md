# 0006：鼠标轴向选高度，滚轮始终缩放

- 日期：2026-10-04
- 状态：采用；替代 0004/0005 中 V 高度阶段的滚轮交互

## 背景

用户要求立体选择先框选底面，再将鼠标限制为上下移动来选高度；滚轮调整高度占用了镜头缩放。Minecraft 的竖直方向是 Y 轴。延续已有六面规则，上下表面选择高度，墙面选择沿对应法线的厚度。

## 决策

V 模式底面拖动仍在起点实际面的固定平面上求交。左键松开后冻结底面并开始高度输入，以释放位置作为鼠标基准与固定 X。无需继续按住左键，鼠标上移向外增加层数、下移向内增加层数，反向可回到底层；下一次左键点击确认。层数包含底面，至少一层。横向移动通过当前游戏窗口的 GLFW 光标位置回到固定 X，不修改底面。世界中显示绿色向外轴线、红色向内轴线及黄色延伸标记。

`HeightSelection` 保存鼠标 Y 基准、亚格累计位移和吸附后的法线偏移，不依赖 Minecraft/Forge。位移按底面端点处一格法线轴投影的像素长度换算；最小每格 4 像素，投影不可用时每格 24 像素。向内/向外采用对称吸附，偏移上限 8191，对应最多 8192 层；实际底面乘层数仍须通过原有 8192 格范围检查。

滚轮只缩放镜头。纯缩放、旋转、平移或升降不修改偏移，新的投影尺度仅影响后续鼠标位移。右键平移或解锁后的中键旋转时，暂停高度输入和光标 X 约束，每次鼠标移动只更新高度基准；释放后从当前位置继续，不能把镜头拖动误记为高度。确认前读取点击坐标，避免漏掉最后一段鼠标位移。

原版鼠标坐标在 `Screen.mouseMoved` 返回后才更新。高度输入使用事件坐标，光标约束通过始终入队的 `Minecraft.tell` 延后，合并同一批输入请求；执行时读取已经更新的最新 Y，避免回放旧 Y 或在原回调内部嵌套 GLFW 回调后被外层覆盖坐标。同 Y 的约束事件不改变高度；已在固定 X 时不重复重定位。执行前重新核验当前界面、窗口焦点、选择阶段和镜头拖动。窗口非活跃时不重定位；失焦、窗口缩放、V 切换、Delete 或退出取消高度状态，停止光标约束。不修改原版光标抓取模式。

普通逐列表面框选、G 追加、立体非空气成员规则、有界加载校验、串行提交及扫描预算不变。

## 验证

纯 Java 测试验证双向层数与底面计数、亚格累积、半格对称吸附、缩放时静止鼠标层数稳定、镜头拖动重新设基准、投影退化时的灵敏度上限、非有限输入、偏移限额、重置和六面范围。

GLFW 回调、光标 X 约束、真实投影灵敏度、轴线渲染与缩放/旋转组合按 [0.1.9 游戏回归](../testing.md#019-鼠标高度与缩放回归) 验收。构建及数学测试不代表这些实际交互已通过。
