# 0007：共享布局的战略工具界面

日期：2026-10-04。状态：采用。

## 背景

原界面把全部快捷键、状态、坐标和选择步骤拼在左上角，既遮挡场景，也难以分辨当前工具。玩家要求先做 UI，之后再继续自定义预设。

## 决策

在当前 `StrategyScreen` 内使用深色半透明 HUD：左上标题、左侧选区卡、底部四个选择工具及阶段提示、右上锁定/帮助/退出。当前工具和追加开启状态使用青绿色，已选数量用黄色。点击按钮调用现有控制器，不新增第二套选择或镜头状态。

纯 Java `StrategyHudLayout` 负责 GUI 尺寸与命中；`StrategyHud` 使用 Minecraft `GuiGraphics` 绘制；`StrategyScreen` 负责输入优先级。共享几何防止看见的按钮与实际点击区域错位，也可覆盖不同缩放和小窗口边界。320×180 下精简信息卡，长文本截断并提供悬停全文。当前只用图元和游戏字体，没有新增字体、贴图、AT 或 Mixin。

UI 区域阻止世界选择和镜头拖动，世界拖动在 UI 内松开取消。事件桥接用共享命中禁止背后悬停与实时框选终点更新，既有选择和扫描任务继续工作。工具栏优先于重绑定鼠标快捷键。帮助在同一 Screen 内显示模态层，暂停镜头和选高，不暂停世界；关闭点击由模态层消费，F6/Esc 仍返回第一人称。

高度阶段悬停 UI 时暂停位移积分和横向约束，进入/离开重设 Y 基准，离开后把当前 X 作为新约束。GLFW 延迟任务执行前复查 UI 命中。原版快捷栏、经验、角色数值栏及药水图标在本会话隐藏，避免重叠，退出通过事件条件恢复。

## 验证与代价

布局和命中可纯 Java 测试；绘制代码可通过临时 AWT 适配输出离线排版图，但适配字体与 OpenGL 不等同 Minecraft。游戏回归必须核验真实字体、鼠标事件、光标约束、按钮状态及退出恢复。此版本不实现新预设模块，也不提供自定义主题和编辑式布局。
