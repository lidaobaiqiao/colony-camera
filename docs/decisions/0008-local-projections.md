# 0008：本地预设与投影

日期：2026-10-04。状态：采用，首版实现于 1.1.0。

玩家需要把自己的建筑保存为可复用设计，并在现有 SLG 界面中定位与管理投影。此次先实现预设、投影和 UI，不引入 NPC、材料扣除或世界修改。

## 数据与持久化

`BlockPreset` 保存名称、UUID、尺寸和已选非空气方块的相对位置、注册名与状态属性。锚点是选中方块包围盒的最低角；不推测普通表面框选中未选中的内部方块，完整结构应使用立体选区。空气不成为清理指令。容器物品、方块实体内部 NBT、实体不保存。

`PresetCodec` 使用 schemaVersion 1、状态调色板和位置数组。`ProjectionCodec` 保存位置、90° 旋转、沿局部 X 的镜像、显示开关及完整预设快照，运行中草稿不落盘。未来不兼容格式须迁移或明确拒绝。字段和数量校验失败、注册方块/属性缺失时拒绝使用，不默默替换成空气。

预设库位于游戏目录 `colonycamera/presets/<UUID>.json`。投影位于 `colonycamera/projections/<世界标识哈希>/<维度标识哈希>/<UUID>.json`；单人世界标识来源于存档绝对目录，服务器标识来源于地址。换存档或维度会清空草稿并加载对应投影。服务器在同一地址替换世界、或单人存档目录移动时没有自动迁移：未来多人规划需要服务端世界标识和同步协议。

先写同目录临时文件再替换，支持原子移动时采用原子替换；不支持时回退文件替换。失败不改变内存中的已确认投影，损坏或未知格式文件保留。文件名只取 UUID，玩家名称不参与路径。单文件上限 4 MiB；预设最多 8192 个方块、单边最多 256 格；当前世界维度最多 32 个投影、共 32768 个方块。

## 输入与渲染

预设库、命名/删除对话框属于 `StrategyScreen` 内部模态层，打开时暂停镜头键盘/拖动输入，并拦截世界点击。取消/关闭不切换 Screen，因此不结束战略会话。`ProjectionPanelLayout` 与 HUD 一样共享渲染和命中几何，覆盖 320×180 GUI 与暂时极小的缩放尺寸。

投影从真实相机射线命中的方块面外侧定位，左键固定后可用方向键、PgUp/PgDn 或面板微调，R/M 旋转/镜像，F 重新跟随鼠标。滚轮在场景和投影面板仍缩放，在预设库中浏览列表。Enter 确认，Esc 先取消草稿/关闭对话框，F6 始终退出会话。改动已有投影时保留原快照，取消不改变原投影。

`ProjectionRenderer` 在 AFTER_BLOCK_ENTITIES 用该帧真实视图和相机位置绘制透明方块模型，模型与线框使用独立缓冲，不向 ClientLevel 写入临时方块。普通模型使用缓存的 baked quads，内部完整方块面省略；移动草稿不重新计算整个预设的深层哈希。资源包模型重新烘焙和世界切换时清除缓存。

缺失方块显示青色，已有不同方块状态显示红色，匹配状态略过重复模型。冲突模型稍向外扩展，避免被原方块深度遮挡；特殊方块、液体等非 MODEL 渲染形状仅显示占位轮廓。不保存或仿真方块实体，不承诺第三方 ModelData、连接纹理、光影与动态机器模型的完整兼容。

统计按帧分批查询并显示“统计中”，每次完成后约 40 游戏 tick 再检查；确认时独立复查区块、世界边界和高度。冲突提示是规划信息，确认不清除障碍物。方块清单表达预设组成，不等于施工需要的物品/配方账单，例如门和床不能直接按方块数量扣物品。

## 后续施工

投影确认仅保存本地规划。NPC、库存和世界修改必须由未来服务端施工系统执行，客户端提交意图。工程优先度高者先分配材料和工人，同优先度按创建时间；所依赖的生产与运输任务继承优先度。不能让不同工程的局部取料行为绕过调度。

Litematica 源码只作为设计研究参考；此版没有复制其源码，没有 MaLiLib 或其他投影模组运行依赖。
