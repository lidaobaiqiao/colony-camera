# 0011：打印核心与有限存储网络

日期：2026-10-05。状态：实现；客户端实际交互待验收。

## 问题与选择

用户反馈工人无法招募，并指出殖民地的开工位置不应受现有工人或角色位置限制。角色附近的测试生成还会受飞行高度影响。改用玩家放置的打印核心作为生成设施，右键及 SLG 工程页均向服务端发出打印意图；服务端在核心周围寻找有地面、净空且允许操作的站位，拒绝原因明确显示。

工程页选择离选中工程最近的已加载自有核心，无工程时按角色位置选择。每核心冷却 20 tick，每玩家每维度最多 8 名已加载工人，打印暂不收费；这些是原型平衡值。工程范围允许围绕角色或自有已加载核心 128 格，不强制加载核心或施工区块。已有工人继续使用原归属和实体持料数据。

仓储直接作为独立设施实现，不依赖 Iron Chests、Sophisticated Backpacks、AE 或投影模组，也不复制第三方源码。所有设施与升级件进入“殖民地”创造分页，具有中文/英文名称、模型、提示、配方和掉落表。

## 有限库存

仓储格子 27/54/81/108，堆叠倍率 1/2/4/8，各自三级升级。不可堆叠物品仍为一件；升级不改变 Item 的全局上限。容量升级件可将未上锁原版单箱转换为 54 格仓储，保留物品、名称、朝向，双箱先拆开；转换遵循 Forge 放置保护，失败恢复而不消费升级件。持升级件 Shift + 右键拆一级，物资会溢出时拒绝。

库存 schemaVersion 1，以单件 ItemStack 模板加整数 count 保存；拒绝未知版本、坏类型、越界、重复槽位和超限数量，原标签保留。菜单按物品及 NBT 汇总类型并分页，预览栈与真实库存分离，原生容器/背包/地面输出最多一个合法原生堆叠。36 个显示格不是仓储的物理格子。

支持左/右键取用、Shift 转移、快捷栏交换、丢出和 Forge 漏斗接口。满仓 Shift 返回无转移结果，不触发原版无限重复。首版拒绝拖拽分配和双击收集，避免将被截断的显示栈写回真实库存。客户端显示大数量，悬停给出精确总量。

## 网络与工程

仓储、一个控制器、任意数量端口和连接块按相邻面连通，归属相同、只查询已加载节点，单分量上限 256。物品始终保存在仓储节点；端口统一存取和自动化路由，不复制库存，不增加容量。多控制器、断连和超限均拒绝网络存取，并显示状态。节点拆除/卸载只改变可用网络，物资保留在原箱；重连后恢复。

工人从地面、独立仓储、普通 Forge 容器或可达端口真实领取物品，再运输施工。控制器不是取料点；已经联网的仓储不额外发布为独立施工来源。多个端口按控制器位置和材料获得同一预约身份，原版双箱也统一身份；先检查另一半已加载再读取合并接口。上锁容器拒绝。实际提取前重新核验网络、权限、数量及路线，沿用工程优先度降序、同级创建顺序。

资源发现不等于已经确认可达；路径检查仍有预算。不可达地面来源短暂缓存，防止它们持续占满仓储取料检查预算。工人持料独立于仓储倍率，继续按当前施工单元领取 1 或 2 件，放块成功后才消耗；暂停和取消保留真实持料。

## 代价与后续

首版玩家及漏斗负责入仓，工人执行工程取料和施工。闲置整理地面物资入仓、库存搜索、物流策略、能量/频道、自动合成、跨维度和居民生活暂未实现。连接块使用完整方块模型；自动化与其他模组容器的兼容需逐个实测。

网络协议升为 2，双方同版安装。工程 SavedData 和原工人 NBT 格式不变；新增设施数据随方块实体保存。独立服务端 GameTest 验证生成、真实箱子交互、回滚、库存守恒及网络优先度，不能替代客户端菜单、创造栏、实体外观、多人消息和性能验收。
