# 0013：相似选择替代表面选择

日期：2026-10-05。状态：采用，1.5.0。

## 原因

用户认为表面框选重复且不适合处理不规则同类方块，要求保留立体选择，将表面模式改为单击相似扩展。相邻包括周围 26 格，单次最大值默认 64、可修改。

## 决定

按 Block 类型判断相同，忽略朝向等状态；种子计入上限。以广度优先顺序扩展面、棱、角邻接，不越过非同类方块或空隙。达到最大值停止并提交已找到的片段，显示上限提示。全局选区仍最多 8192；G 追加继续取并集并去重。

删除旧逐列表面扫描和预览，保留固定实际命中面的立体底面、鼠标高度输入与滚轮缩放。完整多材质结构使用立体选择。

纯 Java SimilarSelectionJob 每步至多一次采样，主线程以 2048 步和约 2 ms 的软预算分帧执行。只读取已加载区块，扫描后复查匹配并在提交前核验依赖区块；变化、卸载或全局超限时保留原集合。整数极值不环绕。查询预算与算法测试不代表客户端 FPS 验证。

工具栏的“上限”弹窗输入 1–8192，保存到 Forge CLIENT 配置 colonycamera-client.toml。无效输入禁用保存，Esc/取消保留原值，保存异常保留旧内存值并提示。弹窗位于原 StrategyScreen 内，避免切换 Screen 退出镜头会话；阻止世界与镜头键鼠穿透，F6 仍可退出。

## 验证

单元测试覆盖 26 邻居、拐角连通、空隙/不同类型阻断、默认截断、单步预算、查询变化/卸载、坐标极值、追加合并和布局边界。实际鼠标操作、配置重启持久化及游戏帧率按 docs/testing.md 验收。
