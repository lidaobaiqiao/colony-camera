# 0015：工人逆流移动与浅水挖掘

日期：2026-10-06。状态：采用。

玩家开采后露出水源，流水进入工作面。普通 Mob 的水中加速度不足以抵消原版流水；仅提高移动速度属性不会同步提高无深海探索者时的水中加速度。旧挖掘站位还排除一切液体，导航按水面高度跟进，与浅水渠底的位置不一致。

使用 Forge 的 SWIM_SPEED 属性，将工人基值设为 5，保留原版流体推动和移动物理，陆地 MOVEMENT_SPEED 仍为 0.3。浮水目标仅在水中头部浸没时启动；普通上浮使用 0.04 脉冲，活动路线要求爬上高于当前位置半格的台阶时使用 0.3 脉冲，防止水平倍率同时放大竖直运动，也避免关闭浅水跳浮后爬不出岸边。熔岩和其他液体继续走原有物理。

LoadedGroundNavigation 使用 WorkerWalkNodeEvaluator，在水中从脚底层起步和跟进，允许水节点，小幅保留水路线代价；不使用原版两栖求路器对水/陆地的偏好改写，也不新增垂直潜泳路径。可达性规划与执行导航仍分离，每次搜索和重算仍限制在已加载区域。

挖掘允许脚部为水、头部空间无液体、脚下坚实且身体无碰撞的站位。打印的干地条件保留，深水、熔岩、无地面位置不得成为挖掘站位。到达并准备开采后停止导航；只有落地、导航结束且仍有工作分配的工人抵抗水流。行走和空闲工人仍受原版水流推动，不给工人永久流体免疫，不传送或忽略碰撞。

加载旧工人时将游泳属性基值更新为 5，避免 NBT 中旧基值覆盖新默认值；保留修饰符、归属、工具、持料和经验。没有新增任务或世界数据格式，不改写用户存档文件。

验证使用独立流水 GameTest 批次：相同水渠中先观察普通推进力，再恢复增强值走完逆流路线；真实挖开水坝，等待自然水流进入后再开采渠底，复查耐久、经验和数量；另覆盖离水台阶、危险站位拒绝及旧属性读档。深水潜泳施工、瀑布竖流、复杂坡道和客户端动画仍需独立验证。
