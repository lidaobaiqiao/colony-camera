# 0016：方块建造目录与自动合成前置

日期：2026-10-06；状态：已实现，客户端实机验收待完成。

玩家从 SLG 建造目录选择方块，在世界放下投影即创建服务端工程。选择目录替代制作单方块预设的繁琐操作，沿用原工程材料守恒、优先度、工人寻路、权限和放置保护。已有的玩家自定义预设流程继续保留。

## 可用性与查询

- 绿色：当前工人可达且未预约的成品资源。来源包括可拾取掉落物、可访问普通容器、自有仓库与网络端口，不包括玩家背包。双箱与网络多端口以原有来源身份去重；扣除公共预约账本。
- 蓝色：没有可用成品，但有可达殖民地合成台，当前材料和产物容量能够完成一次正常工作台配方。使用 CraftingService 与真实执行一致的库存事务预演判断，原料需位于站点三格内可触及的自有仓储/网络中。
- 红色：当前无法取得成品或执行生产。支持的方块仍可规划等待成品；施工不支持的物理或放置类型明确提示且禁止选择。
- 初次查询期间为灰色；查询按服务端 tick 分步执行，每层每 tick 最多四次路径/配方检查，并受约四毫秒预算限制。规划导航不改变工人正在行走的路线。服务端查询节流，放置时重新验证。

目录提供中文名称、ID 和模组命名空间搜索，词项同时匹配，类别、收藏、可建筛选及滚动网格。收藏保存在既有 CLIENT 配置中。类别是本模组的检索分组，不冒充原版创造栏分类；状态同时有文字和颜色。

## 工程和生产

客户端只发注册物品 ID、位置、旋转和服务端目录提供的生产意图。服务端重新生成小型预设；门与床保存完整双格结构，消费一件真实物品。一般方块使用默认状态，方向可旋转，高度可调；更复杂状态可继续使用自定义预设。

蓝色工程同时产生一个关联合成任务，优先度和创建序号继承父工程，使用同一工人池与预约账本。先生产真实产物到仓储，再由施工取用；配方的多余产物留在仓储。父工程暂停、取消、完成或移除同步停止未完成前置；提交双方全部验证后才落盘，拒绝不能留下孤儿任务。一个关联任务也占用既有任务名额。

生产扩展为真实服务器正常有序/无序 3×3 BlockItem 配方，保留设施/工具目录与原科技门槛。不支持特殊动态配方、熔炉或递归材料生产链；地面原料需清扫入站点仓储后才能参与合成。落在红色状态的工程等待成品，不自动推导未知生产链。

工程 SavedData 和附加任务 SavedData 升级为 schemaVersion 2，分别增加 palette 标记与 parentProject 关联；读取版本 1 时使用 false/无关联，保留原预设、材料、进度、优先度和序号。未知或损坏数据继续只读并保留原始内容。

建造投影来自服务端工程快照并随 SavedData 重连恢复，不写入客户端本地投影文件。施工完成/取消后停止显示。construction 通道升级协议 3，新增 building 通道协议 1，客户端与服务端必须安装同版本。

## 验证

JUnit 验证筛选、收藏、滚动和多个 GUI 比例下绘制/点击共享几何。独立服务端 GameTest 验证真实掉落物建造、无序配方自动生产后建造、可用资源扣预约、路径查询不干扰实际导航、有序配方/满仓拒绝、父子任务生命周期、格式迁移、拒绝无残留及门床旋转。构建、服务端和空值分析记录见 validation/1.6.0.md；真实客户端输入、布局和投影视觉单独验收。
