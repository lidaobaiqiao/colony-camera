# 0017：单选、相似与立体作为独立工具

日期：2026-10-06。状态：采用，1.6.1。

## 原因

相似替代表面选择后，非立体点击总是扩展邻接同类方块，遗漏了只选择单个方块的操作。连续建造又占用场景左键，原工具切换没有释放草稿，使玩家难以返回选择。

## 决定

进入 SLG 默认单选，只提交当前摄像机射线实际命中的一个方块。工具栏提供单选、相似和立体三项；相似仍按 26 邻接与可配置单次上限扩展，立体仍拖底面再选择高度。所有工具共用追加、去重及全局上限。

纯 Java SelectionState 保存当前工具及上次点击工具，V 在立体与上次单选/相似之间往返。清空不更改工具，退出会话重置为单选。操作捕获开始时的模式；明确换工具先取消未完成作业，已提交集合保留。

选择工具释放尚未放置的建造/预设草稿，不移除已保存投影或已受理工程。UI 继续先于世界动作处理；左键选择只改客户端选区，不直接挖掘或下单。

## 验证边界

JUnit 检查工具往返、跨工具追加、会话重置及十按钮布局命中。发布构建与 ECJ 空值契约检查不代表真实鼠标、画面和多人验收，按 testing.md 的 1.6.1 清单独立检查。
