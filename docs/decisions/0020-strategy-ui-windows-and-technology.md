# 0020 — 战略界面、独立建造窗口与现有科技

日期：2026-10-06。状态：已实现于 1.7.0，客户端实机验收待完成。

## 决策

采用 docs/ui/ui-design.md 的双端底栏和二级菜单。左侧建造/投影，右侧挖掘/清扫/殖民地；不再常驻选择或清空按钮。中键短按循环单选 → 相似 → 立体 → 追加，第四步回到上次单选/相似并打开追加标志。SelectionState 仍只有三种算法，G/V 和鼠标重绑定继续有效。

PointerGesture 在四个物理像素处锁定拖动分类，返回原点不能重新变成短按。锁定角度时也记录拖动；UI、失焦、会话退出会释放手势。菜单/帮助暂停选高并重设基准，修改工具则取消未完成选区并保留已提交集合。

## 窗口与草稿

BuildWindows 管理最多八窗、叠放、焦点和指针捕获。BuildPanel 保留各自搜索、分类、筛选、收藏视图和选择；冻结的方块注册表索引共享，避免每次多开都扫描全部物品。布局矩形使用同一几何对象进行绘制和命中，WindowGeometry 按可用视口归一化保存到 CLIENT 配置，缩放后夹取位置与尺寸。

BlockDraftState 是当前会话的完整草稿快照：投影 UUID、物品、位置/旋转/镜像、跟随/指针有效性和高度偏移。场景只绘制活动窗口的草稿，切换窗口先保存旧草稿，再恢复新草稿。服务端受理的回执按 UUID 更新原窗口，即使它已经被其他窗口遮住；重复或不匹配回执不能推进新草稿。只有布局和收藏跨会话保存，草稿不跨世界恢复。

已受理的工程属于服务端；关窗口或取消本地草稿不取消它，也不改变资源预约。蓝色自动合成、优先度/FIFO、持料归属和 1.6.2 寻路规则继续使用现有服务。

## 面板与数据

WorkPanel 提供任务、合成、科研概要、人物、工程五页及明确的 open(Tab)。人物仅显示实际已加载工人的 UUID、挖掘等级/经验、工具和在途分配；不填充未实现的姓名、饥饿、心情。

科研概要进入独立 TechnologyPanel。服务器在原有科技快照附加四个节点的名称、前置、材料和耗时；客户端可以检查锁定阶段，仅对真实下一阶段且有效研究台提交现有研究意图。现有研究任务排队时不重复下单。科技/任务的 SavedData 格式和玩法不变，不新增净水、农业等设计稿占位科技。

进度条使用夹取后的比例，列表步进 27、行高 25，面板高度根据内容计算；详情截断和滚动/气泡保留完整文本。HUD 的绘制层级与输入优先级一致，菜单头不能触发被遮住的顶栏按钮。

## 验证边界

JUnit 覆盖模式往返、物理像素手势、重复回执、布局归一化、小视口及进度夹取。服务端 GameTest 覆盖现有施工、挖掘、清扫、合成、研究和流水寻路。ECJ 检查全新二进制及每个主文件的跨文件空值契约。

AWT 预览调用实际 GUI 绘制代码，使用替代字体、占位物品图标和夹具快照，不能代替 Minecraft 客户端、真实纹理、鼠标事件、联机或帧率验收。
