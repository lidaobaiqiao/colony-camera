# 0026：工人状态初版的实施与迁移

日期：2026-10-07。状态：已实施，数值仍待平衡。上位玩法性质由 [0024](0024-worker-state-attributes-professions-stress-loyalty.md) 管辖，本文件的数值、类结构和扫描范围均为可调整的实现选择。

## 必须成立的结果

- 十八项属性分别映射实际行为；对应工作的有效时间和主动学习是成长来源。职业提供独立基础效果加成及对应成长加速，不代替当前能力数值；独有能力按能力路由交给实际模块。属性点数无硬上限，不保留第二套挖掘等级曲线。
- 兴趣只影响出生点数；性格提供固定的一对效果增益/减益。更换职业保留已获得成长，设施条件是硬门槛，兴趣/属性不匹配是可付代价的软门槛。
- 房间和居民一对一，但不限制打印或普通工作。2026-10-07 用户纠正后，1.10.1 取消打印住房门槛；无房或住房已满也能打印，有空房时可自动分配。既有工人完整保留，不能为迁移删除或重建其材料、工具及能力。
- 压力源可归因、罢工可恢复；恢复前让出工人，不复制或丢弃持料及累计工作。默认零忠诚不影响普通工作，只有生活改善使其增加、满压力危机使其减少。
- 特殊指令只接受玩家主动意图；真实路径、交互保护、伤害和目击成立后才影响结果。目击不使用距离替代视线，单事件去重、转述衰减；献身没有虚构的直接生命消耗，士气只对忠诚足够的真实目击者暂时生效。

## 当前实现选择

`WorkerState` 使用 BigInteger 保存出生点数与有效成长积累，基础斜率为 168000 tick（七个游戏日）增加一点。匹配职业默认二倍成长，各职业可单独配置；两项职业同样匹配时采用较高速度，不叠乘。出生兴趣每种提高两项对应属性一点；性格效果默认正负各 5%。同一个实体 tick/同一属性的工作积累去重。

| 属性 | 独立效果映射 |
| --- | --- |
| 生命 | 20 加点数差平方根 × 独立系数，写入真实最大生命 |
| 饥饿 | 独立饱食上限与消耗下降，消费真实食物 |
| 防御 | 点数差平方根映射真实护甲 |
| 移速 | 对数增长写入真实移动属性 |
| 攻击 | 独立线性映射真实近战伤害 |
| 感知 | 独立平方根视距映射资源搜索和导航范围；观察者与工人目标的感知共同决定目击距离，仍要求真实视线 |
| 机动 | 独立对数映射真实跨阶高度和攀爬速度 |
| 精力 | 独立对数映射疲劳消耗与睡眠恢复 |
| 挖掘 | 独立线性破坏进度倍率，保留正确工具及科技门槛 |
| 建造 | 独立平方根速度映射实际动作 tick |
| 搬运 | 独立对数速度映射取料/入库动作 tick |
| 携带 | 独立整数容量，施工批量领取与附近同类清扫实际使用 |
| 心理承受 | 独立承受阈值及恢复速度；UI 仍显示 0–100 |
| 制造 | 独立对数倍率推进合成和研究的有效工作 |
| 学习力 | 独立平方根倍率推进学堂课程；研究员和教师的能力实际消费 |
| 环境抗性 | 独立平方根映射实际火焰、溺水、坠落、寒冷和爆炸伤害；不免除全部危险 |
| 工艺精度 | 独立平方根映射原生耐久附魔品质档，制作实际耐久工具；不增加物资数量 |
| 操作效率 | 独立对数倍率影响实际工作站和学堂设施的使用 |

实际实体属性与动作受 Minecraft 的数值范围、整 tick 时间分辨率等物理限制；这些保护只约束效果计算，不截断已存点数或积累。对应系数逐项在世界 `serverconfig/colonycamera-server.toml` 中配置，没有全局工作倍率。UI 成长条显示下一点的比例，点数不是 Lv；超过 64 位的十进制显示截断，但保存完整值。

住所标记放在房间内部。当前识别同一脚底层连通的可用地面，要求坚实地板、二格净空、脚底之上 2–5 格有屋顶、完整床头床尾且只有一张床，地面为 4–128 格；木门作为边界，即使打开也不增加房间面积。重复标记通过同一床位去重，居民 UUID 随设施持久保存。区块卸载不释放认领；死亡/销毁及跨维度迁移释放原住所。查询只读取已加载世界。人口另有性能配置限制，默认 32、范围 1–128，不再固定为旧版八名。

实际导航支持木门开关。`WorkerDoorGoal` 使用原版开门目标，在每次开关前以真实殖民地归属校验世界交互权限与 Forge 右键方块事件；受保护的门保持原状态。权限拒绝不会释放住所认领，铁门仍须玩家提供实际控制方式。开关只读取已加载位置，不通过穿门或瞬移进入房间。

学堂有三个等级，升级件在原方块上消费。一级基础职业，二级高级职业，三级队长/司仪、双职业与高级课程构成解锁层；课程进度受学堂等级、阶段、学习力和操作效率加速。同属、在同一学堂实际学习且能互相看见的教师加速同伴学习，离场、停学、罢工或不同殖民地均不生效。默认职业训练需累计 2400 有效课程 tick。兴趣不匹配、相关属性不足时学习半速并积累强学压力；双学位还检查心理承受的软条件，在学期间增加额外压力，完成后增加对应属性积累。职业与课程切换不会扣掉旧点数。

工人在连续工作 12000 tick、休息不足或压力较高时主动轮换，饥饿时取用可达地面食物或仓储/网络中的真实食物，仍检查归属、保护和已有预约。不使用运输持料当作食物，碗等余料实际掉落。住所内休息更快，暂无住所也可缓慢恢复，避免旧殖民地在升级后立即停止。压力满 100 罢工，降到 40 以下且休息恢复后重新参与调度。

首版生活改善由住所、房间面积、食物质量和恢复休息产生，空闲时间本身不赠送忠诚。日常小压力不消耗忠诚。默认拒绝指令及单次目击冲击为 5，转述为四分之一；事件冲击不能单独把旁观者从正常状态推过满压力阈值，避免直接清空忠诚储备。各门槛、速率和增益可独立调整。

处决需要实际接近及攻击，遵守 Forge 伤害事件、世界交互保护和 PvP 设置；忠诚对象不反抗，忠诚不足的工人尝试实际逃离。完成时记录真实目击者，忠诚目击者不转述，低忠诚目击者只向同殖民地、近距离可见工人转述一次。UI 区分目击与听闻两种压力来源。献身绑定已有工程/任务，普通调度仍遵守优先度与 FIFO，不强制跳过高优先任务；保留实际危险与火焰寻路代价变化，完成/真实死亡分别给予不同的临时士气。

携带超过原版堆叠时，主手保存一个原生显示栈，额外真实数量以整数随 `ColonyState` 保存。取用从真实库存分批提取，消耗、入库及死亡掉落按原生堆叠处理，不能用 `ItemStack.Count` 的 byte 字段保存总量。施工在工人真实身体离开待建形状之后才推进，不通过删除碰撞或瞬移解决站位问题；低优先任务不能将未完成高优先工程的持料改签给自己。


### 职业框架与独立行为边界

六层十六职业全部可学习、更换、叠加并随实体保存。每个职业绑定一至两条现有属性，并拥有唯一能力标识。默认成长二倍，基础效果通常为 1.05 倍；建造工为 1.12 倍，以在整 tick 动作精度下立即缩短施工动作。所有职业值分别配置，双职业同属性使用较高加成，避免复合无上限堆乘。

现有模块已消费三种独有能力：工匠精品工具（真实耐久附魔，不复制材料）、研究员（学习力加速真实研究）、教师（在场同堂教学）。其他能力的状态接口与描述已定义，但整树、农艺、脚手架、高级机器、医疗以及艺术、战斗的具体行为仍待其独立模块；人物页明确显示待接入，不能把标签或属性加成称为这些行为已经实现。艺术产出后续调用生活改善/压力/临时士气接口，不能走与生活无关的直接忠诚发放。0024 第九、十、十一节明确将具体战斗 AI 和艺术机制排除在本文范围。

本文件使用 0026 编号，为 0024 已预留的 0025 任务调度设计保留位置。

## 保存与兼容

- 工人 `ColonyState` schema 1：十八项出生值/成长、兴趣性格、职业、压力来源、忠诚/生活、历史挖掘计数、住所、学习/特殊指令及持料额外数量。严格验证后整体加载，坏或未知字段/版本保留原 tag 并停止调度。
- 旧工人无 `ColonyState` 时，旧 `ColonyMiningXp` 只用于恢复已达到的挖掘属性点与历史计数；旧主/副手和归属原样保存。旧阈值只留在迁移函数中，此后成长使用有效工作时间。
- 设施 `Living` schema 1 保存居民与学堂等级，未知/坏格式保持只读，并在拆除时保存到原生方块物品 NBT。
- `ColonyWorkManager` schema 4 增加合成/研究的 `workProgress`；1–3 迁移时默认为零，旧挖掘进度仍按原格式迁移，未知版本及坏数据原样保留。当前格式缺少必要工作进度不假装成旧数据。
- 工作网络协议 2 提供人物状态、设施、学习及特殊指令。客户端和服务端必须使用同一发行版本。

升级前备份完整世界。回退到旧 JAR 必须恢复升级前备份：旧版实体读取器不了解新的工人状态，不能保证降级时保留新字段。

## 验证边界

自动验证覆盖纯状态成长/危机性质、真实服务器的房间/学习/食物/罢工/目击、超原版堆叠施工及工作进度守恒。客户端显示、按键/滚动、原世界长期经营、多人保护插件和大人口 TPS/FPS 仍须实机验收，不用编译或加速 GameTest 代替。记录见 [1.9.0](../validation/1.9.0.md)。
