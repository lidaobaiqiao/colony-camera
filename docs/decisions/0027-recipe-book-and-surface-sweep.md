# 0027：完整工作台配方、任务标记与顶面清扫

状态：1.10.0 已实施。日期：2026-10-07。

## 玩家要求

殖民地合成不能局限于固定的工具/设施清单，基础原木也必须能生产木板。界面采用原版配方书形式，让玩家看到全部工作台配方，以及当前什么能做、什么不能做。挖掘目标用黄色标记，清扫目标用蓝色标记；清扫收取选中方块顶部的掉落物。

同时处理工人已接近工作点却没有真正抵达、仍显示工作中而停止的问题。0021、0022 和 0024 的工作、导航、状态与物资守恒性质继续适用。

## 必须成立的结果

1. 默认目录展示已加载世界的全部工作台配方，不要求玩家先解锁原版配方。未解锁科技、缺材料或不能自动生产均保留可见并解释原因；熔炼、切石、锻造不冒充工作台配方。
2. 正常工作台生产使用服务器真实配方的输入匹配、产物及余料，不将展示数量当作扣料依据。工具科技按实际产物判断，替代配方 ID 不能绕过门槛；物品 NBT、容器余料、仓储容量和既有预约均参与事务。
3. 可制作颜色对应当前所选设施与批次数量的真实预演。浏览目录不能移动资源、占用预约、改变执行导航或完成任务；实际下单和执行仍独立复查。
4. 清扫只处理玩家实际指定的顶面，不把非连续选区扩成整个包围盒。其他层、缝隙、遮挡在另一个表面上的物品不属于下层选择；半砖等使用其实际碰撞表面。
5. 拾取前再次判断物品是否仍属于该选区；来源移动、满仓、断连或任务变化都不能造成复制/丢失。空手工人仍须等待本任务的其他持料入仓。
6. 工作点必须可站立、可见且可达；粗略距离不足以证明可操作。导航继续保留真实移动与卡住检测，不以传送、强制加载或不断重启同一路线代替到达。
7. 任务标记独立于鼠标选区，服务端受理后可一直查看；暂停保留，完成/取消移除。网络同步大小受限，客户端标记只读已加载世界。
8. 格式迁移不能改变已有清扫任务的含义；坏数据、缺少辨别字段或未知版本原样保护，不能猜成一个新范围后执行。

## 1.10.0 的实施选择（允许后续替换）

- `CraftingService` 动态解析普通 `ShapedRecipe` / `ShapelessRecipe`，最多九个输入格；非空正常产物可为任意物品并带 NBT。原固定清单只保留工具科技映射和历史辅助接口。建造前置仍另外筛选 `BlockItem`。
- `CraftingPanel` 使用原生图标、搜索输入、五分类、翻页、3×3 输入和产物格；灰色检查中、绿色可制作、红色不可制作，数量 1–64 次。特殊/动态配方仍显示，但需要原版工作台手工制作；没有手工指定输入的殖民地自动生产流程。
- 客户端使用原版已同步的配方注册表；服务端只查询当前页，最多 24 个配方 ID。设施、真实库存、预约、科技、余料与产物空间共同决定状态；批次模拟以前一轮库存结果继续。任务快照不再重复发送完整配方目录。
- 可制作查询最多检查 16 条独立规划路径、八个设施站位；当前优先检查一名实际能到站的同属工人。高复杂度或特殊配方可能无法被自动生产，明确显示状态，不绕过世界物理限制。
- 新清扫意图提交最多 8192 个不重复方块，挖掘与精确清扫合计最多 32768 个指定目标；按精确集合判断成员。掉落脚底须处于所选顶面附近的一格高度内，且其下方到顶面没有其他碰撞表面阻挡；半砖及台阶按物品脚下碰撞部件计算表面，存储仍为自有仓储或有效网络端口。
- 清扫拾取与入仓均寻找可见、可站立且有路径的位置；合成及入仓抵达站位中心后复查实际视线。仓库顶棚等遮挡不能让入仓反复选择同一个不可操作位置。沿用执行导航的末节点跟进，不复位仍有效的同目标路径。
- `WorkTargetMarks` 查询本玩家任务，合并黄色待挖坐标、蓝色精确顶面与旧清扫范围；每页坐标合计最多 2048，签名相同只发确认。`WorkTargetRenderer` 集齐匹配请求和维度的页面后整体更新，只绘制已加载方块。标记在 SLG 视角中显示，通常两秒内刷新。
- “仅可制作”筛选渐进检查当前分类/搜索中的配方；默认全部目录立即可见，可制作子集随着服务端确认补齐。

1.10.2 替换其中清扫的站位选择与到位要求：有效来源、仓库和站位继续保留，入仓由实际距离与视线证明，不再强制精确中心；临时任务清空后可恢复交付。合成的固定工作站规则保留，见 [0028](0028-sweep-delivery-continuity.md)。

## 保存与兼容

附加任务 SavedData 从 schema 1–4 迁移为 5。`SWEEP` 新增显式 `surfaceSweep`：新选择为精确顶面列表，旧任务保留两端点立方体。schema 5 缺少这个字段时拒绝加载并原样保护；制造进度、挖掘进度、优先度和归属保留。

工作网络协议由 2 升到 3：新清扫请求使用精确列表，并新增配方页状态与任务标记页。客户端/服务端必须同版；升级前备份世界，降级恢复旧备份。工人 ColonyState 与设施 Living 的 schema 1 不变。

## 验证边界

独立服务器验证原木→木板→木棍、食物及余料、预约/库存只读预演、批次与满仓、绕墙作业、精确/半砖顶面及来源移动、旧范围迁移和真实大消息分页。纯 Java 测试检查配方书几何和小屏命中；完整空值检查保持开启。

客户端真实字体/物品模型、键鼠输入、黄蓝轮廓、多人和原世界持续工作仍须实机验收，不能由服务端测试代替。完整记录见 [1.10.0](../validation/1.10.0.md)。
