# 0029：类型筛选、物品清扫与人物/住所配置

日期：2026-10-08。目标版本：1.11.0。

## 用户意图

立体选择前可以指定多种方块，只提交匹配类型的成员；清扫可以按多种物品类型收取殖民地内所有可达掉落物；工人需要真实装备与任务配置，住所需要检查详情与自定义配置。

本次按温和默认实现有限的当前物品批次，以及住所名称、指定住户、自动入住设置。物品清扫不是常驻规则；房间合规标准沿用现有规则，不通过设置凭空创建合规房间。

## 必须成立的结果

- 类型筛选按方块注册身份匹配，不因朝向等状态拆分同一种方块。空筛选保留原有立体选择行为；单选和相似不受它影响。排队扫描使用不可变筛选快照，改变设置不能改写已提交选择。
- 客户端选择仍只查询已加载世界。选区不修改世界，挖掘意图仍由服务端受理精确状态并执行原版挖掘链。
- 按物品清扫遵守物品类型、归属、真实距离、路径、视线与拾取事件。不可达物品不阻断其他可达物品，完成前等待该任务实际持料入库。
- 所有任务继续共享优先度/FIFO、工人池与预约账本。人物任务开关只限制个人任务资格，不提高低优先工程在全局的排序。
- 关闭任务不得销毁、复制或挪用已持材料；原任务持料可以继续交付。空手后不再领取被关闭的工作。工具自动领取可以关闭，手动配置的工具仍受实际工具/科技检查。
- 装备必须来自真实库存并保留名称、附魔、耐久等 NBT。主手运输材料不参与装备交换；物品已变化、槽位不适用、绑定诅咒或旧装备无法完整放回时，双方保持原样。
- 住所配置基于真实合规房间、一房一人和殖民地所有权。自动入住关闭不驱逐现住户；显式入住不能抢占同一床所在的房间。卸载住户不能被当成空位。
- 配置未知或损坏数据只读并原样保存。无房、房满或关闭自动入住都不限制打印。
- 所有弹窗先消费键鼠输入，避免误选区、旋转、缩放或改变高度。新增功能不增加常驻底栏按钮。

## 1.11.0 实现选择（可替换）

- `TypeSelection` 是纯 Java、最多 64 个类型。`RegistryPicker` 使用原生物品图标、原生字体与 EditBox，按本地化名称/注册 ID 搜索、翻页、多选。筛选在当前镜头会话内保留，退出会话清空；每个立体扫描在确认时捕获快照，完成时再次核对成员类型。
- 投影菜单新增“立体方块筛选”。清扫按键打开小弹窗，保留“选中方块顶部”并新增“按物品类型”；人物详情新增任务/装备页；殖民地菜单、人物页与右键住所均可进入住所详情。
- 按物品下单时捕获当前已加载匹配掉落物 UUID，范围为下单位置和最多 63 个已加载自有打印核心周围 128 格，最多 8192 个掉落实体、64 个物品类型。后续新掉落不进入本任务；收完当前实际可达成员后结束。物品种类包含所有注册物品，不限方块物品。
- `ItemSweepService` 在派工时分步进行真实取用站位/路径检查，每名工人每轮最多检查 16 个附近掉落候选；不可达结论须涵盖所有仍有清扫资格的本殖民地工人。休息中的工人等待恢复后再检查。路线规划与执行导航隔离。
- `SweepService` 继续负责真实拾取、同标签近处合批与入仓，保留 0028 的来源/仓库/站位连续性。有限批次 UUID 和类型写入任务；路径检查记录仅为临时运行数据，重载后重新检查。已不在已加载范围内、已移除或不再匹配的实体不参与当前可达批次。
- `WorkerPreferences` 保存建造、挖掘、清扫、合成、科研五个开关及自动取工具；旧工人默认全部开启。建造/清扫持料有原任务身份时保留交付资格，不能因此领下一轮材料。
- `WorkerEquipment` 在合法意图下原子交换玩家物品栏中的一件物品与工人对应原生装备槽。工具使用副手，护甲使用头/胸/腿/脚。旧装备完整放回玩家物品栏；没有创造免费装备分支。工具科技不因手动装备而绕过。
- `Residences.details` 报告合规与失败原因、检查面积、床头及实际住户。房间标准仍为 4–128 格有支撑地板、脚底上方 2–5 格屋顶、一张完整床。住所名称最多 64 字符；指定住户和解除认领由服务端处理。解除同时关闭该住所自动入住，避免下一轮立即重新占用。

## 保存与协议

- 附加任务 SavedData schema **6** 从 1–5 迁移。旧精确顶面和更早立方体语义保持；schema 6 清扫必须含 `surfaceSweep`、`itemTypes` 与 `sweepDrops`。类型任务有独立锚点列表，不能被任务标记误画成旧区域清扫。
- `ColonyPreferences` schema **1** 独立于原 `ColonyState`，后者保持原样。缺少新字段的旧工人按默认设置初始化；不完整、未知字段或未知版本保存原始 Tag 并停止相关写入。
- 设施 `Living` schema **2** 从 1 迁移，新字段 `automaticHousing` 必须是合法布尔值，旧版默认开启。名称沿用原生 `CustomName`；人口与物品数量不随格式迁移改变。
- 工作频道协议 **4**；服务端/客户端安装相同版本。更新前备份世界，回退旧版使用升级前备份，不能让旧版解释 schema 6/新人物设置。

## 验证

纯模型检查筛选快照、无筛选默认、类型/数量边界及任务独立性。独立新世界的 GameTest 检查真实装备交换/失败原子性/原生护甲/保存、实际建造开关、自动工具开关、跨所有权拒绝、住所占用与迁移、有限物品批次的真实清扫、不可达/非匹配/他人/后来掉落保留、持料关闭任务后交付及坏任务数据保留。

结果及客户端待验收边界记入 [1.11.0 验证](../validation/1.11.0.md)。服务端通过不代表界面在真实客户端已验收。
