# V1 初版 · 1.0.0

Minecraft 1.20.1 / Forge 47.4.0 / Java 17。客户端模组，安装到客户端 `mods`，同一实例仅保留一个 Colony Camera 版本。

V1 完成从第一人称进入战略视角、自由操作镜头、选择世界方块和使用战略工具界面的基础体验。玩家自定义预设与殖民地施工会在后续版本建立在此基础上。

## 初版功能

- F6 切换第一人称与 SLG，默认锁定角度，F7 解锁后中键旋转；右键/WASD 平移，空格/C 升降，Shift 加速，滚轮始终缩放。
- 摄像机按鼠标位置检测实际方块轮廓；白框悬停，黄框已选，左键单选或沿方块面框选，各列选择最外侧表面。
- V 立体选择先拖底面，松开后上下移动鼠标选高，再点击确认；固定底面并约束横向位置，支持六个面上的高度或厚度。
- G 追加并去重，Delete 清空与取消。选区和立体范围有 8192 格上限，越界、未加载或超限操作保留旧选择。
- 中文/英文战略 HUD，可点击表面、立体、追加、清空、锁定、帮助和返回；显示真实绑定，简短阶段提示与悬停全文。
