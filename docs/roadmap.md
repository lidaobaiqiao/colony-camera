# 开发路线

核心循环：第一人称搭建设计 → 保存自定义预设 → SLG 视角布置规划 → 殖民地执行施工 → 回到现场改进设计。优先实现一条能游玩的循环，再扩充经营内容。

1.8.0 已替换挖掘调度，按站位连续作业、空间分工和持久单块进度推进；真实服务端对照见 [验证记录](validation/1.8.0.md)。1.8.1 修复可挖目标让位和工具领取站位，见 [修复验证](validation/1.8.1.md)；原世界、大选区和客户端验收待完成。后续施工重构按 [0022](decisions/0022-construction-algorithm-baseline.md) 的脚手架目标另行推进，本次没有将施工改为脚手架流程。

1.9.0 接入 0024 的属性、住所、学堂、职业、压力/轮换、忠诚与特殊指令，并提供人物界面。首版数值为独立的温和占位值，实际客户端经营体验、大人口性能与进一步数值平衡继续验收；实现/迁移见 [0026](decisions/0026-worker-state-first-implementation.md)。

1.10.0 补齐正常工作台配方生产和配方书式界面、真实可制作状态、黄色挖掘/蓝色清扫任务标记及精确顶面清扫，修复合成/搬运粗略到位后的停工问题。见 [0027](decisions/0027-recipe-book-and-surface-sweep.md)；实际客户端和原存档长期行为继续验收，递归生产链与特殊动态配方仍待独立推进。

1.10.1 取消打印住房门槛，开局可先打印工人再建设住房；住房只影响居住、生活与学习，人口性能上限独立。服务端回归和交付见 [验证记录](validation/1.10.1.md)。

1.10.2 修复清扫的目的地遗失、反复换站位和等待精确中心，增加远处交付恢复与多工人入仓回归；见 [0028](decisions/0028-sweep-delivery-continuity.md) 和 [验证记录](validation/1.10.2.md)。原世界长期经营及大人口性能继续实测。

1.11.0 加入类型立体筛选、有限批次物品清扫、真实装备/任务开关与住所配置，见 [0029](decisions/0029-selection-item-sweep-worker-and-home-settings.md)。持续清扫规则、合规标准定制、NPC 从仓库配送装备与更广生产链继续按后续需求推进；客户端和大人口经营仍需实测。

## 0：视角基础与工程整理

`0.1.0` 视角已在 2026-10-03 获得用户正常运行反馈。工程整理版本为 `0.1.1`，目标是分离镜头状态、输入与界面，提供可复现构建、必要状态测试及开发说明，同时保持现有操作。

完成条件：构建和产物核验通过；重构 JAR 完成 [视角回归](testing.md)。原型反馈不能替代重构后的游戏验收。

V1（1.0.0）已完成镜头、选择与战略 UI 的初版开发里程碑，包括可点击工具栏、选区信息、短阶段提示与折叠帮助。用户于 2026-10-04 确认初版开发完成；布局、输入所有权和产物有自动检查，详细游戏回归及性能/兼容性实测继续单独记录。1.1.0 已实现本地预设与投影，自动验证通过后仍须完成投影游戏验收。

## 1：保存与重新放置一个自定义结构

先支持区域选择、捕获方块状态、定义锚点、保存和载入。预设含格式版本、尺寸、方块数据和材料清单。第一次实现就明确空气、方块实体数据和旋转的支持范围，未支持内容给出可理解的反馈。

完成条件：玩家亲手搭建一个小结构，保存后重新载入，在 SLG 中获得位置明确的预览；保存文件重启游戏后仍能使用。预览与实际放置分开，格式兼容性有测试。

## 2：由预设形成规划

支持移动和旋转预览、地形冲突提示、确认与撤销。先实现单个结构，再验证道路重复段与连接端；转角、路口需要能表达的连接规则，不凭外观猜测。

完成条件：玩家用自己的路段规划一条道路、用自己的住宅规划多个位置，能看到规划和材料需求且尚未修改世界。

## 3：最小施工闭环

引入服务端确认与施工队列，逐步落地方块，处理资源不足、已有方块冲突及任务中断。以 NPC 真实取料、运输和施工为最小完整循环，遵循工程优先度、同优先度按时间排序、材料预约及前置任务继承规则，再扩展生产链。

先验证无仓库开工：工人从可达地面掉落物捡料并完成简单结构。随后接入独立箱子与格子/堆叠分别可升级的仓储箱；再用统一端口查询、存入和提取有限容量网络的全部物资。箱内总量不等于可用资源，网络多个端口不重复计算库存；不要求材料先存仓再施工。阶段方案和验收见 [决策 0009](decisions/0009-reachable-resources-and-storage.md)。

1.2.0 已落地地面阶段：工程创建、严格优先度/FIFO、真实捡料运输施工、暂停/取消和工程 UI。1.3.0 接入打印核心、普通箱子、容量/堆叠独立升级仓储以及有限网络的统一端口，多个端口共享预约。1.4.0 接入选区挖掘、清扫、工人技能与真实工具、殖民地合成台和研究台；服务端场景覆盖物品守恒、不可达、补料、保护事件、保存恢复、科技扣料和跨任务优先度。1.4.1 补齐设施/升级件的原版配方书解锁与殖民地生产，原版工作台能制作第一套设施。下一步完成客户端交互、多人和性能验收，再评估闲置搬运、自动生产前置链和居民模拟。

完成条件：同一个自定义预设从手工建造、保存、规划到自动施工完整走通，异常时能暂停或取消，不悄悄破坏已有建筑。

## 4：让设计影响殖民地

按玩法需要引入入口、床位、设备和物流接口，让结构实际组成决定功能和效率。再考虑居民生活、生产链以及设计版本替换。避免仅给任意外壳指定固定产量。

完成条件：玩家改进建筑布局后，殖民地运行出现可观察变化；改进后的设计可以保存并继续复用。

0.1.3 已加入角度锁定/解锁与鼠标环绕、拖拽操作，实际回归见验证记录。切层、远程区块加载、复杂气体温度模拟和第三方投影兼容，按具体需求独立评估。这里不承诺日期，也不把后续功能的空包或占位接口当作完成。

## 1.5.0 选择交互简化

按用户需求，相似选择替代表面扫描：26 邻接、默认每次 64、界面可调整并保存，立体选择保留完整多材质结构操作。2026-10-05 用户确认 1.4.4 挖掘和存储可用；新选择交互继续按 testing.md 实机验收，再推进殖民地生产和经营扩展。

## 1.6.0 方块建造与生产前置

已实现可检索方块目录、可达成品/可执行生产颜色、直接放置工程、一次合成前置及暂停/取消/优先度联动。独立游戏验收覆盖 UI、连续放置、多人快照和存档恢复；不把单步工作台生产表述为完整递归生产链。下一步依据游戏反馈改进规划和实际生产设施，再推进更复杂物流与经营。

## 1.6.1 单选、建造持料与紧凑界面

补回默认单方块选择，保留相似与立体；选择工具可结束连续放置。建造目录缩为窄栏和放置工具条，隐藏闲置卡片。清扫与建造持料区分任务归属并支持旧工人恢复，目录施工接受可替换植物。后续按 testing.md 验收输入、视觉及原世界的施工恢复，不把服务端测试当作客户端验收。
