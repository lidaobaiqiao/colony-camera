# 生存合成指南

适用版本：1.4.1，Minecraft 1.20.1 / Forge 47.4.0。

## 从原版工作台开始

九种殖民地设施和升级件均使用原版 3×3 工作台配方，无需其他模组。取得工作台后，配方书解锁打印核心、殖民地合成台和研究台；箱子解锁仓储箱，铁锭解锁容量升级件，红石解锁堆叠升级件、网络控制器与端口，铜锭解锁连接块。

在工作台左侧配方书搜索物品名称，即可查看材料和摆放位置。材料不齐时关闭可合成筛选。旧存档已有材料时，可把对应物品取出再放回背包触发解锁；不需要重建存档。

| --- | --- | --- |
| 打印核心 | 铁锭 ×5、红石 ×2、玻璃 ×1、原版工作台 ×1 | 1 |
| 殖民地仓储箱 | 铁锭 ×8、原版箱子 ×1 | 1 |
| 殖民地合成台 | 铁锭 ×3、任意木板 ×3、原版工作台 ×1 | 1 |
| 研究台 | 铁锭 ×2、任意木板 ×3、书 ×1、原版工作台 ×1 | 1 |
| 容量升级件 | 铁锭 ×8、纸 ×1 | 1 |
| 堆叠升级件 | 绿宝石 ×2、红石 ×2、纸 ×1 | 1 |
| 存储网络控制器 | 铁锭 ×4、红石 ×4、下界石英 ×1 | 1 |
| 存储网络端口 | 铁锭 ×6、红石 ×2、漏斗 ×1 | 1 |
| 存储网络连接块 | 铜锭 ×2、红石 ×1 | 8 |

## 启动殖民地

1. 先用原版工具采集并熔炼材料，在原版工作台制作打印核心、仓储箱、殖民地合成台；准备研究时再制作研究台。这些设施不需要殖民地科技。
2. 放下自己的打印核心并右键打印工人；在殖民地合成台旁三格内放置自己的仓储箱，把后续生产的材料存入箱子，保留工人站位和取用路线。
3. 右键殖民地合成台或在 SLG 下按 O →“合成”，选择设施、升级件或工具，设定次数并提交。工人完成后从真实库存扣料，并把成品存回仓储。
4. 中期制作网络控制器、端口和连接块，把仓储接入网络；合成台附近的有效端口可为工人提供整个网络中的材料。

次数表示配方执行次数：两次连接块配方消耗四个铜锭、两个红石并产出十六个连接块。仓储必须放得下整批产物；剩余容量只能容纳一个连接块时，不能生产一批八个。缺料、满仓、遮挡或断网会等待，不会免费产出或吞料。

设施生产不会自动合成前置箱子、工作台、书或漏斗，也不会自动熔炼矿石；这些组件须先备齐。石、铁、钻石工具仍遵循殖民地科技解锁。
