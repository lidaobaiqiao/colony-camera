# 验证与验收

## 当前基线

2026-10-03，用户确认 `0.1.0` 的视角功能正常，并确认 `0.1.5` 的选中效果已生效。反馈保留为对应功能基线，不代表已执行下面的全部回归。当前 `0.1.8` 改为中键旋转、右键平移，普通框选逐列跟随最外侧表面，V 底面加高度操作保留，必须独立游戏验收。

## 分层验证

| 层次 | 要证明什么 | 不能证明什么 |
| --- | --- | --- |
| 纯 Java 状态测试 | 平移、归一化、缩放范围、边界约束等计算正确 | Forge 事件实际触发、画面及输入恢复 |
| Gradle 构建 | Java 编译、资源处理、打包和混淆任务通过 | 游戏加载和交互正确 |
| JAR 检查 | 入口、拆分后的类、语言文件及访问转换器进入交付包 | 安装实例加载了该包 |
| 安装核验 | 交付 JAR 与测试实例 `mods` 中的 JAR 相同 | 运行效果正确 |
| 游戏内验收 | 摄像机、按键、生命周期在真实客户端工作 | 所有光影或其他模组组合都兼容 |

纯 Java 测试围绕边界和不变量：斜向与轴向平移速度一致；缩放达到上下限后仍保持范围；超出水平活动半径时正确限制；无输入不移动。不要只断言方法调用自己产生的值。

当前 `CameraState` 使用 JUnit Jupiter，运行 `.\gradlew.bat test`；构建使用 `.\gradlew.bat build`。`build` 同时执行 `verifyArchitecture` 与 `verifyModJar`，检查边界及包内容。`scripts/build.ps1` 的交付归档位于 `dist/<version>/`，附 SHA-256 与 `verification.json`。摄像机无法通过无界面单元测试完整验证。

选择的纯 Java 测试覆盖原子提交、并集去重与上限、闭区间及整数边界、长方体合并准确性与洞保留、六个命中面的射线求交、负坐标、固定半格面、反向拖动、实际命中终点保留切向坐标、法线正负层数及投影变化后的世界范围。表面作业测试覆盖每列最外侧目标、六方向顺序、空列与空轮廓、搜索窗口、分帧推进和中途不可用的失败语义。纯 Java 测试不能证明真实鼠标事件、Minecraft 高度图/区段/区块适配和预览渲染已生效；实际交互与耗时需要游戏测量。

## 游戏内回归清单

使用测试存档和独立测试实例，记录 MC、Forge、模组版本，以及是否有光影或其他摄像机模组。

1. 第一人称进入世界，切换键进入 SLG，确认默认角度锁定、60° 俯视画面、鼠标自由显示。
2. 锁定时中键拖动不旋转；WASD 和右键仍可平移，滚轮仍可缩放。斜向速度一致，Shift 加速；角色没有因这些按键行走。
3. F7 解锁，中键拖动改变朝向与俯角；上下限 15°/85° 不翻转，水平角度连续绕圈。旋转后 WASD 按当前镜头朝向移动，右键拖拽使画面跟随鼠标；不同 GUI 缩放下灵敏度一致。
4. F7 重新锁定保留当前角度且再次禁止旋转；长按 F7 不连续切换。重新进入 SLG 恢复默认角度锁定。滚轮缩放到上下限、平移到活动范围边缘，画面保持稳定。
5. 空格/C 上下移动，只改变镜头高度，不改变角色位置、俯角和缩放距离。锁定/解锁均可用，Shift 加速；重绑后操作和提示一致，同时按上下键停止升降，斜向+升降没有额外加速。
6. 对照静止、WASD、右键平移、中键旋转和升降时的 FPS 与平滑程度；在 60/144 FPS 下不应出现旧的 20 Hz 台阶运动。拖动中失焦、暂停/退出后恢复时不产生补跑长距离。帧率明显下降需结合实际实例继续分析，不能以数学测试声称 FPS 问题已经解决。
7. SLG 中将鼠标移到角色触及距离外的已加载方块，白框随鼠标准确移动。改变朝向、俯角、距离、FOV、GUI 缩放和窗口比例后，边框仍对应屏幕中目标；检查台阶、栅栏等实际形状。
8. 默认普通模式左键松开后单选出现黄框，HUD 名称与坐标正确；移动鼠标后保留选择并可悬停其他方块，追加关闭时点击空处取消。目标变为空气或所在区块卸载时，后续分帧检查清除对应成员。
9. SLG 中角色身体、持物、准星和攻击指示隐藏；原位火焰/水下/窒息、南瓜或模组头盔、望远镜及冻结遮罩不干扰镜头，原位玩家视线的旧高亮不出现。其他玩家正常显示，世界继续运行，本地角色仍按原规则受伤。
10. SLG 状态点击鼠标，确认未触发角色挖掘、放置或攻击；右键和中键拖动继续执行镜头操作。
11. 切换键与 Esc 均能返回第一人称，之后可正常移动、转头、挖掘及切换物品；准星、攻击指示、持物与所有上述视野遮罩按当前角色状态恢复，再次进入不保留旧选择。
12. 在按键设置中更改视角切换键与角度锁定键，验证新键工作，界面提示与绑定一致。
13. 连续切换；进入时按住移动键再退出；拖动中切出窗口再回来，确认没有粘键或镜头持续移动，新的鼠标按下才能开始拖动。
14. 从 SLG 离开世界、重新进入；检查视角、晃动选项、选择与输入没有残留。
15. 若出现死亡、重生或界面被替换，确认 SLG 能正常收尾且可以再次进入。

## 0.1.6 多选回归

此节保留为 0.1.6 历史验收清单；当前版本使用下方的 0.1.8 表面框选与中键旋转回归。

1. 普通模式左键移动不足 4 个物理像素仍单选，达到阈值显示青色画面矩形，松开后开始框选。检查正反方向拖动、窗口边缘、GUI 缩放与不同分辨率；松开后移动镜头，作业仍采用松开时的画面。HUD 显示计算中并保持界面可操作。
2. 框选不同距离的地面、墙面、台阶、栅栏和密集混合场景，检查已采样表面目标与黄框。记录极小目标可能漏选的情况；缩小范围、放大画面或改用立体选择复核，不能把框选解释成对所有可见方块的完整枚举。
3. G 按一次开追加，后续单选、框选和立体选择取并集，重复选同块不增加数量；无需一直按住 G。再按 G 关闭，下一次成功操作替换。开启时点空处保留，关闭时清空；长按不连发。
4. V 进入立体模式，点击两个角点，中途平移、旋转、升降镜头；青色预览包含两个角点及其间全部格子。第二点完成后仅计算非空气方块，内部遮挡方块仍入选。交换两角顺序以及只选同一角点时结果一致，V 再次切回普通模式。
5. 在测试存档选择含空气的立体区域，确认 8192 格边界可处理，超过边界时预览红色并提示；8192 个已选方块的并集再增加新块、未加载区域及框选复杂度失败时，保留旧选区而非提交部分结果。跨区块立体扫描期间卸载已扫过的区块，确认提交前完整范围复查仍拒绝结果并保留旧选区；世界边界外区域也应整体拒绝。
6. 对完整实心结构、空心结构及异形块混合选区，核对数量与轮廓。合并轮廓不得填洞、纳入未选方块或将台阶/栅栏替换成完整方块；大选区缓存分帧构建后显示完整轮廓，观察实际 FPS 与计算耗时。
7. Delete 清空并取消作业、排队操作和未完成两角，之后旧作业不能重新提交。拖动中窗口缩放或失焦应丢弃拖动；作业/两角等待时失焦取消未完成操作并保留已有集合。F6/Esc、离开世界或界面替换清空集合与全部模式，再次进入恢复默认。
8. 将 G/V/Delete 分别重绑到其他键盘键及鼠标键，验证实际提示与操作一致、长按只触发一次、与镜头拖动的输入优先级正确。新按键及所有选区点击均不得触发角色挖放攻击。
9. 连续提交追加与替换操作，确认执行顺序、每次操作开始时的模式以及 HUD 数量正确；队列过满有提示，Delete 和失焦能终止剩余操作。被选块变为空气或区块卸载后分帧移除，不阻塞主线程。

## 0.1.7 面框选与高度回归

此节保留为 0.1.7 历史验收清单；固定起始面与 V 高度阶段仍保留，但当前普通框选按下方的逐列表面规则验收，镜头鼠标键也以 0.1.8 为准。

1. 普通模式在地面上表面按下左键，移动不足 4 个物理像素后松开仍执行单选；达到阈值后出现世界中的青色四边矩形，松开选择底面一层。检查反向拖动、负坐标、跨区块、不同 FOV、GUI 缩放与窗口比例，范围包含起点和终点格。
2. 分别从 UP、DOWN、NORTH、SOUTH、WEST、EAST 六个面开始框选，矩形沿被点击面的两个方向扩展，法线轴保持起点格所在层。拖动时鼠标跨过其他高度或不同朝向的块，不应改换起始平面；前景遮挡也不改变固定底面。
3. 从半砖和台阶的实际半格面开始，四条预览边保持命中面的真实高度；最终选择对应格子中的非空气块，并按 OUTLINE 形状显示黄框。检查栅栏等小面；镜头位于方块内部产生的命中不能启动面框选。
4. 在平行于起始面、交点落在镜头后方、鼠标越界或交点超出可选距离的姿态尝试拖动，确认无效操作不能提交旧的有效底面或部分结果。失败提示明确，已有选择保留。
5. 按 V 进入立体模式，在上表面拖出底面后松开，进入高度阶段。从初始底层向上滚动向外增加层数、向下滚动向内增加层数，反向可减回底层；上表面的向外为向上、向内为向下，至少保留底面一层。例如三层应包含底面加两层，空格也计入范围。左键点击任意画面位置确认后选中所有非空气格，包含被遮挡的内部。
6. 从下表面及四个墙面重复底面加高度操作，检查正方向沿面法线向外、负方向向内；下表面的向外为向下，墙面选择为横向厚度。层数切换不得出现零体积，预览与确认结果的格子范围一致。
7. 高度阶段使用 WASD、中键拖动、空格/C、Shift 和解锁后的右键旋转，底面保持固定；此时滚轮只改变层数。确认后滚轮恢复镜头缩放，再次选择从新按下的面开始。普通底面拖动中启动中键或右键操作应取消底面，不应误提交。
8. 验证 8192 格扫描边界和 8192 个选区成员边界：范围含空气，超限预览及确认失败；追加并集超限时保留旧集合。包含未加载区块、越过世界高度或世界边界时整体拒绝。扫描中途卸载已扫描区块，提交前完整范围复查仍应拒绝，不提交部分选择。
9. G 追加开关与单选、面框选及立体选择组合，成员去重，关闭后下一次成功操作替换。开启时点空处保留、关闭时点空处清空；新选择保存操作开始时的追加状态，连续操作保持提交顺序。
10. Delete 取消底面、高度、作业与排队操作并清空集合；失焦或窗口缩放取消全部未完成操作，包括高度阶段，保留已有集合。恢复后旧操作不能重新提交。F6/Esc、离开世界、死亡/重生或界面替换继续走会话收尾，再进入时状态重置。
11. 重绑 G/V/Delete 为键盘或鼠标键，检查提示、连发抑制及输入优先级。所有点击仍不触发原角色挖掘、放置或攻击；镜头角度锁定只限制旋转，不限制选择或平移。
12. 密集选区观察分帧扫描与轮廓缓存：HUD 计算状态可见，镜头继续可操作；完整方块合并不填未选洞，异形块保留实际形状。记录扫描、提交与缓存构建阶段的 FPS 和耗时，256 格/约 2 ms 的软预算不能代替性能实测。

## 0.1.8 表面框选与中键旋转回归

1. 默认锁定状态下中键拖动不旋转，右键拖动平移；F7 解锁后中键旋转并调整俯角，右键仍平移。确认上下限、当前朝向下的 WASD、滚轮及空格/C 不受交换鼠标键影响，退出后原版鼠标交互恢复。
2. 在同一框选范围中放置平地、坡地、凹坑和不同高度的叠放方块。从上表面左键拖动，参考矩形保留起点高度，蓝色待选轮廓随各列真实高度；松开后每列只选最上面的一个可选方块，数量与列数对应，不遗漏较高/较低目标，也不包含内部叠层。终点停在高台或低谷的实际方块上时，范围应沿该方块的切向坐标结束，不能因投影到起点高度而横向偏移；终点指向空处时仍使用固定面求交。分别从低到高和从高到低重复。
3. 从下表面选择不同高度的悬空结构与洞顶，核对每列选择最下方目标；空列不增加成员。测试六个面、负坐标、跨区块以及反向拖动，面内两轴范围包含起止格，外侧方向跟随命中面法线。
4. 测试半砖、台阶、栅栏、草/花及带液体的表面。实际轮廓非空的方块可入选，空轮廓液体略过后寻找同列下一可选目标；蓝色和黄色描边保持实际形状。参考平面的半格高度仍保留，内部起始命中不能启动面框选。
5. 上表面测试普通地形、地下起点及起点上方结构，核对每列按世界有效高度选最上层，而不是只在起点附近找目标；下表面检查最低有效高度附近与含多个空区段的结构。分别在主世界、下界/自定义高度维度核验高度范围，不能把高度图或跳空区段的单元模拟当作游戏适配已通过。
6. 从四个墙面测试起点前后 32 格范围内不同厚度的结构，每列沿对应外侧取一个目标；范围外方块不得入选。让搜索扩展边缘遇未加载区块，窗口应缩到所有列共用的连续已加载范围，不跨缺失区块选择更远的目标；所框范围本身未加载则整体拒绝。
7. 表面预览和提交扫描期间让依赖区块卸载，确认整个作业拒绝并保留旧选择，不提交已完成列；已选成员的区块卸载后分帧移除。重新加载后需重新发起操作，不能延续使用旧冻结窗口。开发检查应直接核对 `getChunkSource().hasChunk`，不要以本版本恒为 true 的 `ClientLevel.hasChunk` 判断测试区块已加载。
8. 大范围拖动时观察蓝色预览分帧增加，完成后应显示全部真实表面。改变范围或空处无效求交后，不应残留旧范围的预览或误提交。拖住左键等待预览完成，让另一玩家在已有顶块上添加新块或移除顶块，再松开：应重新查询新表面，不提交被埋住的旧块或因旧块移除而漏掉下层。墙面加载窗口应以松开时的状态重新冻结。每帧最多 2048 项/约 2 ms 的预算同时覆盖列范围查询与采样，但必须另记录 FPS、查询与提交耗时。
9. 核对最多 8192 列和最多 8192 个成员的边界；空列也计入范围，超限、世界边界越界或追加并集超限均保留旧集合。G 开关追加并去重，关闭后下一次成功操作替换；操作保存开始时的追加状态并按队列顺序执行。
10. V 模式仍以固定起点面拖底面，松开后滚轮调整沿法线的高度/厚度，再左键确认；此操作不自动跟随地形。范围包含空气且最多 8192 格，确认后选择其中非空气成员，包括遮挡的内部；V 保留旧规则，不使用普通表面的空 OUTLINE 过滤。高度阶段右键平移、中键旋转及键盘移动保持底面不变，滚轮只调层数，确认后恢复缩放；立体扫描每帧仍最多 256 格/约 2 ms。
11. 普通底面拖动时启动右键平移或解锁后的中键旋转应取消拖动；Delete 取消表面预览、提交扫描、排队操作或高度阶段并清空，失焦/窗口缩放取消未完成操作并保留旧集合。F6/Esc、离开世界及界面替换重置会话，旧作业之后不得重新提交。
12. 重绑 G/V/Delete 为键盘或鼠标键，验证提示、连发抑制和输入优先级。所有选择及镜头鼠标操作均不得触发原角色挖掘、放置或攻击。密集表面选区仍检查完整块合并不填洞，异形块不变成完整方块；实机结果按 JAR 哈希单独记录。

## 0.1.9 鼠标高度与缩放回归

1. V 开启后左键拖底面，松开无需继续按住；光标 X 固定，上下移动只调整高度，横向移动不改变底面或层数。再次左键点击确认。普通表面框选仍保持 0.1.8 规则。
2. 鼠标上移向外、下移向内，反向回到底层。核对整数吸附与底面计数；六个面均沿对应法线延伸，上/下表面为 Y 高度，墙面为 X/Z 厚度。绿色轴向外、红色轴向内、黄色标记随偏移移动。
3. 高度阶段让鼠标保持静止，滚轮缩放到不同距离并核对层数、世界底面和选区不变；随后上下移动鼠标继续选高，灵敏度随投影变化。按 WASD/空格/C 移动镜头也不能凭空改变层数。
4. 高度阶段中键旋转（先 F7 解锁）与右键平移须释放横向限制并暂停高度更新。松开后从当前 Y 继续，不把镜头拖动距离加入高度；连贯操作缩放、镜头拖动与选高，确认底面固定、层数无跳变。
5. 改变 GUI 缩放、窗口比例、FOV、俯角及镜头距离，核对原始窗口坐标换算、真实投影灵敏度与轴线位置。接近正视法线或底面移出视野时也应有受限灵敏度，无 NaN 或无限层数。
6. 横向移动触发光标约束后，新 Y 必须保留，不产生旧 Y 回放、反复回调或光标抖动。切换窗口、按 V/Delete、F6/Esc、离开世界或窗口缩放后，鼠标恢复自由，旧高度状态不能继续提交。
7. 选区过大、超世界高度/边界或含未加载区块时保持红色预览并拒绝确认，保留旧集合；鼠标缩回有效范围后可继续确认。G 追加保持开始操作时的模式并去重，确认仍只选非空气成员。
8. 记录实际安装 JAR 哈希及本版本游戏结果。上述 GLFW、渲染和交互不能由纯 Java 测试代替。

## 0.1.10 战略界面回归

1. 进入 SLG 核对标题、左侧选区卡、底部四工具和阶段提示、右上锁定/帮助/返回；默认表面工具和角度锁定有青绿色标记，完整快捷键不再常驻。原版快捷栏、经验/角色数值和药水图标隐藏，返回第一人称后全部恢复。
2. 点击表面/立体工具，核对状态与 V 同步；重复点击当前模式不反复切换。追加按钮与 G 同步，清空与 Delete 同步，锁定与 F7 同步。悬停显示完整说明和实际绑定，鼠标重绑定在场景生效，但 UI 点击仍优先。
3. 点击标题、选区卡、工具内外边距或阶段提示，不应选中背后方块或移动镜头；白色悬停框在面板上消失，移回场景恢复。从场景拖框到 UI 松开应取消本次底面，不提交被遮挡目标；反向从 UI 按下拖到场景不启动框选。确认都不触发原角色挖放/攻击。
4. 核对空选区、单选名称与坐标、多选数量、追加状态、扫描提示和错误通知。长名字、长按键名称、英文和限额/未加载通知截断后可悬停查看全文；错误提示不能被普通阶段说明覆盖。
5. 在 320×180、480×270、640×360 GUI 尺寸和窗口比例变化下检查面板/控件边界、工具高亮、文本留白及中央场景可选择。小尺寸信息卡省略次要行，放大后恢复。窗口缩放继续取消未完成选择并保留已选集合。
6. 高度阶段进入 UI 暂停选高及 X 约束，点击追加/锁定/帮助不误确认。离开 UI 从当前位置继续，不把穿过面板的 Y 距离计入层数。回归场景中的滚轮缩放、中键旋转、右键平移及延迟 GLFW 任务；模式切换/清空/失焦/退出收尾仍正确。
7. 打开帮助后尝试 WASD、升降、滚轮、左右/中键，镜头和层数应不变；已有扫描仍可完成，世界继续运行。帮助显示真实 F7/G/V/Delete/升降/切换键。点击 × 或面板外关闭，关闭点击不选择背后方块；随后操作正常。F6/Esc 仍退出战略会话。
8. 静止镜头观察 GUI 字体、透明度和图元；不能把离线 AWT 排版图当作真实 Minecraft 画面验收。分别记录可安装 JAR 的 SHA256、实际字体/鼠标结果和其他 HUD 模组兼容情况。

验收记录至少包含日期、JAR 文件名、SHA-256、测试实例版本、通过项及失败项。可用 PowerShell 核对交付包与实际安装包：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '交付 JAR 的绝对路径'
Get-FileHash -Algorithm SHA256 -LiteralPath '测试实例 mods 中 JAR 的绝对路径'
```

两者哈希一致才说明验收对象相同；测试实例中避免保留同一个模组的多个版本。报告未通过或未执行的项目，并将日志、截图与对应 JAR 关联。开发客户端成功后仍需验证可安装的混淆 JAR。
