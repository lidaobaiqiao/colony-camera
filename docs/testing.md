# 验证与验收

## 1.13.0 UI 首轮（真实客户端待验收）

双方建议使用同版，在测试副本中检查；协议与存档格式保持 1.12.0。实现边界见 [UI 记录](ui/implementation-1.13.0.md)，自动证据见 [1.13.0](validation/1.13.0.md)。

1. 中文/英文、320×180、400×225、480×270、640×360、960×540 GUI：人物检查器不覆盖底栏，六页、前后按钮、长文本换行、滚动和 Ctrl+Tab 都可使用。18 项属性仍在成长页，生活/关系分开，忠诚没有被当作 0–100 的压力条。
2. 打开建造目录后进人物详情，确认建造窗仍显示；人物外可平移、缩放和选择。人物内右/中键、滚轮不能传给世界；弹出菜单/帮助时点击其与人物重叠部分，只响应最上层。退出或失焦后无挂起输入。
3. 任务窄屏至少三行，点击/Enter 进入详情；原生字体下完整原因、序号和工人信息可滚动查看。返回恢复所选对象和列表位置，暂停/优先度/取消只作用于所示 UUID，来回切换后隐藏按钮不误触。
4. 配方默认全部，查询/缺料/科技/无法自动生产有明确状态。窄屏搜索并翻页，点配方看材料、产物和批量，下单后返回列表；搜索、页码及批次数保留。详情页原格子所在位置不能改变选择；隐藏生产按钮不接受点击。原木四木板、替代材料、配方余料和入库仍实际守恒。
5. 科研直接显示八个真实节点，正常窗两列；窄窗选节点进入详情，再返回。工具与生活前置正确，效果与阻塞原因优先可见，长材料清单可滚动。没有前置、没有工位或已经排队时不能重复提交，实际进度仍来自服务端。
6. 建造条目同时有状态符号与短说明，绿/蓝/红不只靠颜色；未确认库存不显示成零。确认自动合成后施工，切换八窗、旋转/高度、命名/保存预设、库存/仓储原生操作及旧快捷键不变。
7. 打印仍无需住所。学习入口返回成长页，高级指令返回工作页；特殊指令弹出确认后核对工人与目标，取消不发命令。对象消失、未知只读、目标变化时不能提交旧按钮；装备选择关闭后只回人物一层。
8. 多人、数据包重载、GUI 缩放、窗口极小、鼠标重新绑定和长时间操作检查；记录真实客户端画面、FPS 与操作结果。纯 Java 布局检查和浏览器设计预览不能作为这些项目已通过的证据。

## 1.12.0 生活与发展（客户端与长期经营待验收）

双方安装同版并先备份世界。科技 schema 2 从 1 迁移；新增独立 ColonyNeeds schema 1，工作协议 5，任务 schema 6 不变。设计和自动证据见 [0030](decisions/0030-colony-life-and-development.md) 与 [1.12.0](validation/1.12.0.md)。

1. 没有住房仍可打印。旧工人载入后初始饮水充足；自然水源不足时只增加对应需求和压力，不能一直占着导航而停工。让工人走到真实可达水源饮水，隔墙、流水及含水实体块不能远程饮用；往返时原任务持料、归属和工作进度保留。
2. 科技树显示八个节点，工具与生活分支独立。先实际饮水，再支付材料研究供水，制造并放置取水站；六面没有相邻自然水源或科技未完成时明确原因，接通后工人实际前往饮水。原版工作台可以预制设施，但不能提前获得设施效果。
3. 建合规住所并实际进餐，再解锁保温与社区；原有仓储、打印、工作台及住所不被新科技锁住。检查材料不足、任务暂停、抢占、取消、保存重进、满仓和设施失效，研究只扣一次真实材料，进度与完成节点一致。
4. 在不同群系、昼夜、雨天、水中以及有墙隔开的热源附近观察人物温度、压力来源和速度。保温仅在实际进入自有合规住所时生效；不是全世界温度模拟，不因这一层温度新增伤害。
5. 两名同属工人走到聚会点、距离足够近且互相可见时产生对称关系与社交恢复；孤身工人、外属工人、隔墙工人及正在执行其他工作的人不能充当聊天对象。没有同伴或地点不可达时不长期停工。确认人际关系与玩家忠诚分别显示、分别保存。
6. 持续提供真实食物、饮水、住所与休息，检查供养回报每天最多一次，读档和倒退世界时间不能重复领奖；重复剥夺和恢复已有生活品质也不能刷忠诚。共同相处后研究公共教育，真实学堂学习叠加既有教师效果；闲置不增加学习属性。
7. 在 320×180、400×225、640×360 GUI 检查八节点科技树、详情滚动、人物六页、中文长文本和键盘选择；材料、实际进度、前置实践及阻塞原因必须来自服务端。进行多人重连与未知/损坏数据检查，不能覆盖只读原数据。
8. 在测试副本中以 8/16/32 名工人经营多个游戏日，混合挖掘、建造、清扫、生产、研究、饮水、睡眠和社交；检查贴墙容器取用与床边入睡连续性，记录 TPS 和实际停工原因。自动化服务器测试不能替代原存档、客户端画面及长期性能验收。

## 1.10.2 清扫连续性（原世界待验收）

在测试副本中使用双方同版 1.10.2，保存/协议沿用 1.10.1。自动证据见 [1.10.2](validation/1.10.2.md)。

1. 在自有仓库约 30 格外放置掉落物，选择其实际顶面下达清扫；工人应连续走到物品、返回入仓并完成任务，不能在约 24 格边界停下。核对数量、名称与 NBT。
2. 工人走向原掉落物时在附近投下另一个物品；有效来源和站位应继续，之后再处理新来源。真正来源移动、消失或遮挡时应复查重选。
3. 多名工人同时交付到一座仓库，实际已触及且可见时即可存放；墙/屋顶挡住视线时仍需绕行。不能因为无法精确对齐中心而一直运输中。
4. 工人在远处拾取后暂停/恢复任务、主动休息或保存退出再进入；持料及任务归属保留，临时任务清空后可重新定位真实可达的自有仓储/端口。
5. 堵住旧站位、撤掉端口连接、改变归属或填满仓库，再恢复条件；核对重新规划和等待原因，不吞掉持料，不交到他人仓库。重复高优先任务抢占，预约、FIFO 及其他施工持料不被清扫接管。

本轮未运行真实客户端，玩家反馈世界中的具体卡住场景和长时间经营仍待复测；服务器用例不代替客户端和大人口性能实测。

## 1.10.1 打印与住房独立（客户端待验收）

在测试副本中使用双方同版 1.10.1，保存和网络格式沿用 1.10.0。自动证据见 [1.10.1](validation/1.10.1.md)。

1. 不搭房、不放床或住所标记，右键打印核心和殖民地 → 人物 → 打印均应成功；出生兴趣/性格、归属与普通工作正确，提示不再要求空房。
2. 仅建一间房并分给既有工人，再打印新工人；新工人没有住所但可以工作，原认领不被抢占。新增空房后可分配，重复标记不能把同一房间分给多人。
3. 检查冷却、人口性能上限、核心归属和安全地面仍生效；无住所时仍按生活规则产生压力和缓慢恢复，职业学习仍检查住所及学堂。

## 1.10.0 配方书与任务标记（客户端待验收）

测试副本中使用双方同版 1.10.0。附加任务迁移到 schema 5，旧清扫保留原范围；降级使用升级前备份。自动证据和范围见 [1.10.0](validation/1.10.0.md)。

1. 殖民地 → 合成、旧任务页的合成标签、第一人称右键殖民地工作台均打开新配方书；默认显示全部原版/数据包工作台配方，未解锁的仍可查看。核对木板、面包、箱子、所有设施和工具，不再只有固定二十五种。
2. 中英文及 320×180、400×225、640×360 GUI 下检查搜索、五分类、图标翻页、材料替代图标轮换、3×3 格及产物数。窄窗口可 Esc/× 关闭，页码与底部按钮不遮挡配方；搜索输入、滚轮、右/中键不透传给镜头、选高或世界。
3. 一根原木可制作一次四木板，两次应红色缺料。库存/预约变化后颜色刷新；科技、无工人、设施消失、无可取库存、满仓和不支持自动生产均明确原因。切换工作台后立即重新检查，不能静默换到另一台；“仅可制作”逐步补齐确认结果。
4. 下单木板→木棍、面包、蛋糕：核对实际原料、产物数量、空桶余料、工人有效制造进度和科技。给材料命名验证 NBT 输入；取消、暂停、优先度抢占、满仓与读档不复制或吞掉物品。
5. 挖掘和清扫分别出现黄色方块轮廓与蓝色顶面。右键清空鼠标选择后仍有任务标记，暂停保留，完成/取消后在刷新周期内消失；其他玩家/维度不串标记。大量目标、区块卸载重载和渲染距离边缘不强制加载远区。
6. 只选两个不相连地面格，三处分别放物品：只收两处；中间、下层和未选上层的物品保留。检查半砖、台阶两个高度、上方另一个半砖遮挡、流水移动掉落和临时障碍。掉落离开指定顶面后须重新规划，不能沿旧预约捡走。
7. 合成台/仓库附近建转角墙，保留可绕路径：工人实际走到能操作的一侧后持续生产/入仓，不停在宽松距离阈值外。再在原反馈世界中重复长时间挖掘、施工、清扫和合成，记录人物/任务状态及位置；服务端回归不能证明所有原地停工场景都已消失。

本轮没有运行真实客户端，上述字体、模型、输入、标记视觉、多人及原存档长期运行均待验收。服务器与纯模型成功分别记录，不能合并为“游戏已测试正常”。

## 1.9.0 工人状态层（客户端与长期经营待验收）

升级前备份完整世界，在测试副本中使用双方同版 1.9.0。工人状态 schema 1、附加任务 schema 4；降级必须恢复升级前备份。自动验证和范围见 [1.9.0 记录](validation/1.9.0.md) 与 [0026 实施说明](decisions/0026-worker-state-first-implementation.md)。

1. 先用原版工作台合成住所标记、学堂、升级件，核对配方书、创造栏和殖民地生产目录。1.10.1 已纠正 1.9.0 的打印住房门槛：没有房间也能打印。玩家搭建坚实地板、屋顶、两格净空、完整单床的 4–128 格房间，放标记后可认领住所；一室多个标记不能重复分配，拆床/屋顶后显示失去住所但不删除工人。
2. 殖民地 → 人物 → 打印配置，测试全部兴趣和可选性格；科学家与急躁组合不能提交。不同出生点数、成对固定效果、默认无职业都可在详情中确认。现有工人的主手材料、副手工具、历史挖掘数和旧属性迁移后保留。
3. 人物详情显示 18 项属性的点数、独立物理效果和成长条，以及压力来源、忠诚、住所、生活状态。测试 320×180、400×225、640×360 GUI 的三页切换、长列表滚动、Esc 和关闭按钮；模态操作不透传镜头或世界选区，缩小到极窄窗口仍能关闭。
4. 不同等级学堂展示六层 16 个职业及各自设施要求；不匹配的兴趣/属性允许强学，实际进度较慢且列出强学压力。更换职业保留成长，三级双职业只在学习期间增加双学位压力。停学、离场、罢工、卸载和读档不能重置已完成课程或替玩家完成课程。
5. 工匠制造同配方工具产生真实耐久品质，原材料数量不变；研究员属性实际影响研究，教师只有同属、同堂、在场和可见时加速同伴。界面必须区分能力已接入与待独立模块；不能把艺术/战斗/整树/农艺等标签视为具体 AI 已实现。
6. 让工人持续挖掘、施工和搬运：对应属性积累，七个游戏日基准不因闲置增加工作属性。观察轮换、休息和饥饿取食，食物来自可达地面或真实仓储并受归属/预约保护；正在搬运的材料不能被当作食物。关闭卧室木门后工人应开门入睡；保护插件拒绝交互时门保持关闭，住所认领仍保留。满压力罢工后恢复，持料和合成/研究累计进度不丢。
7. 携带成长后观察大堆叠的真实往返次数，保存退出再进入核对实际数量；取消、满仓、断网和死亡掉落分别核对守恒。高优先工程持料不能被低优先工程改签，工人必须离开待建碰撞区域后放置。
8. 提升感知、机动、精力、环境抗性与操作效率后，分别测试搜索距离/双向目击、台阶/梯子、睡眠需求、真实危险伤害与设施耗时；仍须遵守已加载区块、工具科技、权限及真实视线。大数点数保留，客户端显示截断不改变保存值。
9. 忠诚 0 的工人照常工作，日常低压力不减忠诚；生活改善才增长，满压力危机才减少。玩家主动下达低忠诚特殊指令时拒绝并显示来源；没有玩家意图不出现处决/献身。处决检查真实路径/伤害/视线，隔墙无目击，转述衰减且限同殖民地；献身保留真实危险并区分成功/失败临时士气。
10. 保存退出、多人重连、区块卸载重载、未知/损坏状态分别检查。未知工人/设施数据须停止相关写入并原样保留；住房居民认领不能因卸载被重复分配。最后以 8/16/32 名工人开展多个游戏日的经营，记录实际 TPS、寻找食物耗时与界面响应；服务端加速 GameTest 不代替这项验收。

## 1.8.1 挖掘可用目标与工具（原世界待验收）

1. 无工具选中泥土、木头与石头的混合区域：先挖允许空手的部分，石头仍留在同一任务；把木镐放到可达地面或自有仓储，任务应自动领取并继续。
2. 工人正在挖石头时移走副手镐，附近有可挖泥土：先处理泥土，石头的部分进度保留，补回工具后继续。技能/科技未解锁的矿石不能影响其他成员的开采，也不能绕过门槛。
3. 仓库入口旁放两格高墙，保留绕行通道：工人应走到能取到工具的一侧，主手持料不丢；拿到工具后回工作面，不停在墙外反复领取。
4. 给工人一把仅剩一次耐久的镐，在仓库放有名称、损耗的备用镐：挖完第一块后自动补领，工具名称和损耗保留，不重复产生掉落/经验。
5. 有其他模组保护的目标和正常目标混在一起：正常部分继续，受保护成员留在工程。保护解除后无需重建工程即可自动复查；保护取消的破坏不磨损、不加经验。
6. 工具不可达、被他人限制拾取、被其他任务预约或受科技限制时继续等待；补领只使用真实已有工具，不凭空生成或自动创建工具合成任务。服务端 GameTest 不代替原世界、客户端动画/同步与复杂地形验收。

## 1.8.0 挖掘调度（原世界与客户端待验收）

升级前备份测试存档，客户端/服务端安装同版并核对 JAR 哈希。schema 3 不能被旧版读取，回退须恢复升级前备份。

1. 三名持石镐工人从 8×4×8 石体南侧开始，选中全部 256 块下达挖掘。观察分工、同站连续开采和最后一层的完成；任务结束后核对掉落、经验及耐久。服务端基准 tick 是对照场景的结果，不能直接当作原世界 FPS/TPS 保证。
2. 多种材料、树叶/草、泥土/木材、石头和深板岩混合选区，检查工具与科技/技能门槛。高挖掘度只参与调度，实际破坏速度仍受工具与等级影响；空气不增加工程总量。
3. 开采中暂停、添加更高优先任务、移除临时障碍或更换工人后继续；已做的单块进度不能反复归零。保存退出再读档，核对目标、部分进度、完成计数和真实工具。
4. 挖掘工人自己或其他工人脚下的支撑，检查先离开再挖；选区外屋顶、设施、箱子、液体与保护事件不能被绕过。
5. 浅流水中从岸边开采、逆流到站并继续开采；头部浸水或没有坚实底部时等待，先排水恢复站位。临时堵路、绕角、台阶、区块卸载与重载分别检查。

5. 按 V 进入立体模式，在上表面拖出底面后松开，进入高度阶段。从初始底层向上滚动向外增加层数、向下滚动向内增加层数，反向可减回底层；上表面的向外为向上、向内为向下，至少保留底面一层。例如三层应包含底面加两层，空格也计入范围。左键点击任意画面位置确认后选中所有非空气格，包含被遮挡的内部。
6. 从下表面及四个墙面重复底面加高度操作，检查正方向沿面法线向外、负方向向内；下表面的向外为向下，墙面选择为横向厚度。层数切换不得出现零体积，预览与确认结果的格子范围一致。
7. 高度阶段使用 WASD、中键拖动、空格/C、Shift 和解锁后的右键旋转，底面保持固定；此时滚轮只改变层数。确认后滚轮恢复镜头缩放，再次选择从新按下的面开始。普通底面拖动中启动中键或右键操作应取消底面，不应误提交。
8. 验证 8192 格扫描边界和 8192 个选区成员边界：范围含空气，超限预览及确认失败；追加并集超限时保留旧集合。包含未加载区块、越过世界高度或世界边界时整体拒绝。扫描中途卸载已扫描区块，提交前完整范围复查仍应拒绝，不提交部分选择。
9. G 追加开关与单选、面框选及立体选择组合，成员去重，关闭后下一次成功操作替换。开启时点空处保留、关闭时点空处清空；新选择保存操作开始时的追加状态，连续操作保持提交顺序。
10. Delete 取消底面、高度、作业与排队操作并清空集合；失焦或窗口缩放取消全部未完成操作，包括高度阶段，保留已有集合。恢复后旧操作不能重新提交。F6/Esc、离开世界、死亡/重生或界面替换继续走会话收尾，再进入时状态重置。
11. 重绑 G/V/Delete 为键盘或鼠标键，检查提示、连发抑制及输入优先级。所有点击仍不触发原角色挖掘、放置或攻击；镜头角度锁定只限制旋转，不限制选择或平移。
12. 密集选区观察分帧扫描与轮廓缓存：HUD 计算状态可见，镜头继续可操作；完整方块合并不填未选洞，异形块保留实际形状。记录扫描、提交与缓存构建阶段的 FPS 和耗时，256 格/约 2 ms 的软预算不能代替性能实测。

## 0.1.8 表面框选与中键旋转回归

表面框选部分为历史清单，1.5.0 已删除；镜头中键行为继续保留。当前选择按下方 1.5.0 验收。

1. 默认锁定状态下中键拖动不旋转，右键拖动平移；F7 解锁后中键旋转并调整俯角，右键仍平移。确认上下限、当前朝向下的 WASD、滚轮及空格/C 不受交换鼠标键影响，退出后原版鼠标交互恢复。
2. 在同一框选范围中放置平地、坡地、凹坑和不同高度的叠放方块。从上表面左键拖动，参考矩形保留起点高度，蓝色待选轮廓随各列真实高度；松开后每列只选最上面的一个可选方块，数量与列数对应，不遗漏较高/较低目标，也不包含内部叠层。终点停在高台或低谷的实际方块上时，范围应沿该方块的切向坐标结束，不能因投影到起点高度而横向偏移；终点指向空处时仍使用固定面求交。分别从低到高和从高到低重复。
3. 从下表面选择不同高度的悬空结构与洞顶，核对每列选择最下方目标；空列不增加成员。测试六个面、负坐标、跨区块以及反向拖动，面内两轴范围包含起止格，外侧方向跟随命中面法线。
4. 测试半砖、台阶、栅栏、草/花及带液体的表面。实际轮廓非空的方块可入选，空轮廓液体略过后寻找同列下一可选目标；蓝色和黄色描边保持实际形状。参考平面的半格高度仍保留，内部起始命中不能启动面框选。
5. 上表面测试普通地形、地下起点及起点上方结构，核对每列按世界有效高度选最上层，而不是只在起点附近找目标；下表面检查最低有效高度附近与含多个空区段的结构。分别在主世界、下界/自定义高度维度核验高度范围，不能把高度图或跳空区段的单元模拟当作游戏适配已通过。
6. 从四个墙面测试起点前后 32 格范围内不同厚度的结构，每列沿对应外侧取一个目标；范围外方块不得入选。让搜索扩展边缘遇未加载区块，窗口应缩到所有列共用的连续已加载范围，不跨缺失区块选择更远的目标；所框范围本身未加载则整体拒绝。
7. 表面预览和提交扫描期间让依赖区块卸载，确认整个作业拒绝并保留旧选择，不提交已完成列；已选成员的区块卸载后分帧移除。重新加载后需重新发起操作，不能延续使用旧冻结窗口。开发检查应直接核对 `getChunkSource().hasChunk`，不要以本版本恒为 true 的 `ClientLevel.hasChunk` 判断测试区块已加载。
8. 大范围拖动时观察蓝色预览分帧增加，完成后应显示全部真实表面。改变范围或空处无效求交后，不应残留旧范围的预览或误提交。拖住左键等待预览完成，让另一玩家在已有顶块上添加新块或移除顶块，再松开：应重新查询新表面，不提交被埋住的旧块或因旧块移除而漏掉下层。墙面加载窗口应以松开时的状态重新冻结。每帧最多 2048 项/约 2 ms 的预算同时覆盖列范围查询与采样，但必须另记录 FPS、查询与提交耗时。
9. 核对最多 8192 列和最多 8192 个成员的边界；空列也计入范围，超限、世界边界越界或追加并集超限均保留旧集合。G 开关追加并去重，关闭后下一次成功操作替换；操作保存开始时的追加状态并按队列顺序执行。
10. V 模式仍以固定起点面拖底面，松开后滚轮调整沿法线的高度/厚度，再左键确认；此操作不自动跟随地形。范围包含空气且最多 8192 格，确认后选择其中非空气成员，包括遮挡的内部；V 保留旧规则，不使用普通表面的空 OUTLINE 过滤。高度阶段右键平移、中键旋转及键盘移动保持底面不变，滚轮只调层数，确认后恢复缩放；立体扫描每帧仍最多 256 格/约 2 ms。
11. 普通底面拖动时启动右键平移或解锁后的中键旋转应取消拖动；Delete 取消表面预览、提交扫描、排队操作或高度阶段并清空，失焦/窗口缩放取消未完成操作并保留旧集合。F6/Esc、离开世界及界面替换重置会话，旧作业之后不得重新提交。
12. 重绑 G/V/Delete 为键盘或鼠标键，验证提示、连发抑制和输入优先级。所有选择及镜头鼠标操作均不得触发原角色挖掘、放置或攻击。密集表面选区仍检查完整块合并不填洞，异形块不变成完整方块；实机结果按 JAR 哈希单独记录。

## 0.1.9 鼠标高度与缩放回归

1. V 开启后左键拖底面，松开无需继续按住；光标 X 固定，上下移动只调整高度，横向移动不改变底面或层数。再次左键点击确认。普通表面框选仍保持 0.1.8 规则。
2. 鼠标上移向外、下移向内，反向回到底层。核对整数吸附与底面计数；六个面均沿对应法线延伸，上/下表面为 Y 高度，墙面为 X/Z 厚度。绿色轴向外、红色轴向内、黄色标记随偏移移动。
3. 高度阶段让鼠标保持静止，滚轮缩放到不同距离并核对层数、世界底面和选区不变；随后上下移动鼠标继续选高，灵敏度随投影变化。按 WASD/空格/C 移动镜头也不能凭空改变层数。
4. 高度阶段中键旋转（先 F7 解锁）与右键平移须释放横向限制并暂停高度更新。松开后从当前 Y 继续，不把镜头拖动距离加入高度；连贯操作缩放、镜头拖动与选高，确认底面固定、层数无跳变。
5. 改变 GUI 缩放、窗口比例、FOV、俯角及镜头距离，核对原始窗口坐标换算、真实投影灵敏度与轴线位置。接近正视法线或底面移出视野时也应有受限灵敏度，无 NaN 或无限层数。
6. 横向移动触发光标约束后，新 Y 必须保留，不产生旧 Y 回放、反复回调或光标抖动。切换窗口、按 V/Delete、F6/Esc、离开世界或窗口缩放后，鼠标恢复自由，旧高度状态不能继续提交。
7. 选区过大、超世界高度/边界或含未加载区块时保持红色预览并拒绝确认，保留旧集合；鼠标缩回有效范围后可继续确认。G 追加保持开始操作时的模式并去重，确认仍只选非空气成员。
8. 记录实际安装 JAR 哈希及本版本游戏结果。上述 GLFW、渲染和交互不能由纯 Java 测试代替。

4. 地面物品在可达处/封闭墙内/高台/水边、拾取冷却和归属限制下逐一检查；搬动物品、玩家先捡走、途中堵路后，不能凭旧预约免费施工，也不能隔墙取料。
5. 暂停正在运输的工程，确认工人停止任务且持料不丢；继续后可完成。取消保留已建方块和持料，随后其他任务可复用；移除记录、编辑或删除本地投影的作用分别核对。
6. 重启/退出重进、卸载并重载工人所在区块，核对工程优先度、进度、暂停/取消、归属与真实持料。工程不强制加载远程区块。
7. 目标有冲突方块、缺支撑、实体挡位或服务器保护规则时，界面原因明确且材料不消失；移开障碍后继续。门/床和双半砖按组计料，旋转/镜像后实际状态正确；不支持的状态应在创建时拒绝。
8. 小窗口/GUI 缩放下三页切换、选中项在优先重排后保留、材料提示与按钮不重叠；面板内点击不穿透为世界选择，滚轮与镜头键保持已有行为。检查中文与英文提示。
9. 其他玩家不能修改自己的工程或使用自己的工人；跨维度/断线重连后不显示旧工程。另一客户端需能看见工人及其真实持料；兼容和网络行为以实际测试结果记录。
10. 当前未实现箱内取料、仓储升级和存储网络，不能将它们登记为通过。记录大量工程与工人下的真实 tick 耗时、FPS 和动态模组方块支持情况。

## 1.3.0 打印、仓储与网络回归

服务端自动场景覆盖已注册创造分页及搜索条目、悬空角色从核心打印并施工、堵塞/外人/冷却拒绝、大数量存取与坏库存保护、普通箱子和仓储取料、实际右键转换及保护回滚、多端口共享库存/断连/补料/优先度以及满仓 Shift 的库存守恒。下列客户端与多人项目尚需实机完成。

1. 双方安装同一 1.3.0 JAR。创造物品栏找到“殖民地”分页，核对五种设施与两个升级件的模型、中文名称及提示，搜索“打印核心”“仓储”也可找到；生存配方按配方文件核对材料与产出。

4. 用容量升级件右键含物品、改过名且有朝向的原版单箱，确认转成 54 格仓储并保留内容；普通右键不要求蹲下。双箱和上锁箱拒绝并提示；服务器放置保护拒绝时仍为原箱，物品和升级件都保留。

7. 一个控制器连接至少两个有不同物资的仓储和两个端口，从任一端口统一查询/存入/取出；工人从端口领取封闭仓储的材料。两名工人争一份材料时高优先先，同级按创建顺序；补料后另一工程继续，端口数量不会翻倍物资。
8. 拆连接块、卸载节点区块、恢复连通或添加第二个控制器，确认状态明确，已存物资保持在真实仓储箱；断连时不能凭旧预约免费施工。用漏斗存取仓储与端口，满仓余料留在来源，跨维度及未加载区块不被强制访问。
9. 保存退出、重启服务端并重进，核对仓储大数量、升级、名称、归属、核心和实际工人持料；拆仓储时正常掉落全部内容及升级，输出原生合法堆叠。坏库存只读保护不得覆盖原数据。
10. 另一玩家不能打印或打开自己的设施；测试多人连接、工人持料渲染及原有 SLG 鼠标门禁，按最终 JAR 哈希记录。真实帧率/tick 耗时、光影和其他模组容器/自动化兼容另行实测。闲置工人自动入仓未实现，不能登记为通过。

## 1.4.0 挖掘、清扫、合成与科技回归

服务端自动场景覆盖选区状态复查与立体挖掘、工具领取/等级/耐久、地面掉落清扫、满仓等待、断网保留主手持料、拾取保护、原版配方事务、研究材料与科技保存、建造和生产共享优先度/FIFO、预约竞争、工作站站位及坏数据只读保留。客户端和多人需安装最终混淆 JAR 后实测。

1. 双方安装同一 1.4.0 JAR。在 SLG 中完成普通表面或 V 立体选区，O → 任务 →“挖掘选区”，确认工人按等级和副手真实工具执行；空手及木/石/铁/钻石工具的门槛、耐久、附魔、名称和原版掉落逐项记录。被玩家替换、液体、不可破坏、方块实体和受保护方块不得被批量拆除。
2. 在已选地面区域生成有归属和无归属掉落，分别测试拾取冷却、封闭路线、玩家先拿走、满仓和断开的网络。O →“清扫选区”后，工人先把物品放到主手，再运到自有仓储/端口；目的地不可用时地面物品和主手持料都应保留，重新连通或腾出容量后能继续。
3. 放置殖民地合成台、研究台及三格内的自有仓储/有效端口。右键工作站与 O 面板两条入口都应显示中文配方/科技材料；合成木棍及木、石、铁、钻石镐/斧/铲，检查真实扣料、产物/余料入库、满仓回滚和次数语义。封闭仓储不得隔墙供料，补料或恢复取用通道后应继续。研究逐级消耗圆石、铁锭/煤炭、钻石/红石，保存重进后等级不丢，锁定配方不能绕过科技。
4. 同时创建建造、挖掘、清扫、合成和研究任务，使用相同材料及不同优先度，确认数字大的先、同级创建早的先；缺料时低优先任务可运行，补料后高优先任务恢复。暂停/取消、来源变化、工人离开、工作站破坏或仓储断连不得吞掉材料、工具或已完成结果。
