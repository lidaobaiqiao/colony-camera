# 1.13.0 UI 首轮实施

日期：2026-10-17。来源：[系统规划](ui-plan-2026-10-14.md)；输入与数据边界：[0031](../decisions/0031-contextual-ui-and-visible-input.md)。本轮是 Java 模组实现，不修改原对话中的浏览器设计样例。

## 已实现

- **统一视觉**：UiTheme 集中正文、次要文字、表面、边界、选中和四类状态色；UiDraw 提供面板、按钮、省略文字和有界进度。HUD、建造、投影、人物、住所、筛选、任务、科研与原生仓储界面使用同一主题。合成保留原版图标/配方书操作，去掉另一套灰色金属边框。
- **人物检查器**：InspectorLayout 按内容和实际 GUI 大小计算右侧矩形，避开底栏。概况、工作、装备、成长、生活、关系六页，学堂和高级指令在对应页内进入并有返回。概况不再列 18 项属性；正文按原字体换行，属性进度保留。窄窗用前后页按钮，Ctrl+Tab / Ctrl+Shift+Tab 切页，滚轮和上下键浏览内容。
- **明确输入范围**：普通人物页不加整屏遮罩，外部仍可选择、平移和缩放；先前已打开的建造窗口继续显示。打印、装备选择和特殊指令确认保持模态。菜单/帮助先于检查器接受点击和按键，下层面板不绘制误导性的悬停提示。
- **退出清理**：离开战略界面同时关闭工作面板、配方接收器和临时确认，避免旧窗口在后台继续接受配方回执；不取消已受理的服务端任务。
- **任务与工程**：宽窗列表/详情并列，窄窗列表至少三行，点击或 Enter 进入详情，返回/Esc 回列表；详情原字体换行并单独滚动，原优先度、暂停、取消、打印等功能保留。
- **合成配方书**：默认显示全部真实工作台配方。窄窗列表最多显示 20 个图标，选择配方进入材料/产物/状态和批次数详情；返回保留搜索、分类、页码、批次和所选配方。隐藏列表和隐藏提交控件不响应。紧凑列表高度按内容收缩。
- **科研**：入口直接打开工具/生活两列的八节点界面；优先选正在研究或满足前置的节点。小窗口选择节点后用完整内容区显示效果、实践/科技前置、材料、工位和耗时，返回后继续看分支。隐藏研究按钮不响应，锁定节点可查看。上下键在列内选择，左右键换分支，Enter 打开；详情可滚动。
- **建造反馈**：网格增加状态符号，目录底部直接显示已有/自动合成/缺料说明；尚未确认的可用库存不伪装为零。搜索、分类、收藏、拖动缩放、八窗草稿和真实工程回执沿用。
- **特殊指令**：提交前显示影响与捕获的目标 UUID；确认只提交当时的完整意图，取消返回原页。没有可用或可写的工人时不能从旧控件确认。

## 保持的边界

客户端只读取现有快照和提交现有意图。任务 schema 6、科技 schema 2、ColonyNeeds schema 1、工作协议 5 等保持 1.12.0；没有改工人调度、库存事务、打印住房要求、方块选择算法或镜头数学。未修改玩家存档和既有版本归档，也不自动安装到玩家实例。

## 后续部分

本轮没有把整份设计稿冒充完成：任务与工程仍为现有两个管理标签，统一筛选视图待后续；住所/投影管理继续使用现有结构和统一主题。世界中直接点工人、镜头定位、建造窗口最小化、全殖民地可达资源总览、统一请求中/超时状态以及进一步的键盘焦点导航仍待独立接入。需要后端字段的项目须明确统计范围与协议边界，不能用客户端模拟数据填充。

实际代码验证与客户端待验收见 [1.13.0 验证记录](../validation/1.13.0.md)。浏览器样例、纯布局测试和编译均不能代替游戏内图标、字体、输入和多人验收。
