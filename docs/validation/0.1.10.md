# 0.1.10 战略界面验证

日期：2026-10-04。

## 行为

战略界面改为独立标题/选区卡、底部四个选择工具与阶段提示、右上锁定/帮助/返回。当前工具及追加开启使用青绿色，已选数量使用黄色。点击现有操作，悬停显示真实绑定和完整文案；小 GUI 尺寸精简信息卡，长文本可悬停查看全文。

共享布局决定 UI 命中，面板内不选择背后方块，世界框选在面板上松开取消。帮助暂停镜头与选高，关闭点击不传给世界。高度阶段进入/离开 UI 重设鼠标基准，UI 内不限制 X；延迟光标任务复查 UI。原版快捷栏、经验/角色数值与药水图标只在 SLG 隐藏，退出恢复。
