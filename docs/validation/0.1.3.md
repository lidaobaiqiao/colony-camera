# 0.1.3 角度锁定与鼠标镜头验证

日期：2026-10-03。

## 功能约定

用户确认：进入 SLG 默认只锁角度，继续允许平移和缩放。F7 解锁/锁定角度，右键拖动旋转，中键拖动画面，滚轮缩放；按键可重绑定。重新锁定保留当前角度，新视角会话回到默认 yaw 180°、pitch 60°、距离 32 并锁定。
