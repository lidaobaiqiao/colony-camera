# 0.1.4 升降与逐帧运动验证

日期：2026-10-03。

## 改动与问题证据

新增空格上升、C 下降，可重绑定；改变世界 Y 的焦点高度，不改变角色位置、俯角或 zoom 距离。左 Shift 加速，锁定角度时仍允许升降。

旧版 WASD 只在 ClientTick END 每秒更新 20 次，渲染每帧直接读取位置，没有插值。因此高 FPS 下也会出现每 50 ms 跳一次的镜头运动。0.1.4 将键盘平移/升降移到 RenderTick START，按单调时钟帧时间推进，保留旧单位时间速度；进入/退出/失焦时重置，单帧最多计算 50 ms 位移。

本机 Forge 47.4.0 / MC 1.20.1 源码确认 RenderTick START 在 GameRenderer.render 之前，而摄像机事件在 camera.setup 后、视锥准备前执行。提示布局改为初始化/缩放/锁定状态变化时更新，渲染帧绘制缓存行。
