# 0.1.6 多选扩展验证

日期：2026-10-03。

## 改动与基线

用户确认 0.1.5 的选中效果已生效；这是对应功能反馈，不代表本版本框选、追加与立体选择已完成游戏验收。

新增普通模式左键松开单选/画面框选、G 追加开关、V 两角立体选择、Delete 清空与取消。HUD 显示数量、模式、追加状态与作业提示；镜头操作与本地角色隐藏保留。

选区集合最多 8192 个方块，立体范围最多 8192 格且计入空气；超限、未加载或框选复杂度失败保留原集合。框选使用冻结视图和分帧自适应采样，极小目标可能漏选；立体选择可包含遮挡内部。轮廓缓存精确合并完整方块，异形块保留形状。
