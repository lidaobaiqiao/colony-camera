# 0.1.7 面框选与底面加高度验证

日期：2026-10-04。

## 改动与基线

0.1.0 的摄像机与 0.1.5 的选中效果已有用户反馈基线；本版修复 0.1.6 屏幕框选的空间含义，新增交互仍待独立游戏验收。

普通框选固定鼠标按下时方块实际命中面的世界平面，鼠标射线与这个面求交，四条矩形边沿实际面绘制；半砖或台阶的半格面保持真实高度。松开后逐格扫描底面所在的一层，不使用屏幕像素采样。

V 立体模式先左键拖底面，松开进入高度阶段，滚轮沿面法线选择向外或向内的层数，再左键确认。层数包含底面的一层，墙面对应厚度。高度阶段可操作镜头，滚轮在确认后恢复缩放；原有 G 追加和 Delete 清空保留。

单次范围最多 8192 格，含空气；选区集合最多 8192 个成员。无效面或交点、超限、未加载区域以及世界高度/边界越界均不能提交部分结果。扫描按 256 格/约 2 ms 的帧预算推进，提交前复查完整范围；失焦或窗口缩放取消未完成操作并保留旧集合。
