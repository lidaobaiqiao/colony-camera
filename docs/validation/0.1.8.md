# 0.1.8 表面框选与中键旋转验证

日期：2026-10-04。

## 改动与基线

0.1.0 的摄像机与 0.1.5 的选中效果已有用户反馈基线，本版仍需独立游戏验收。中键在 F7 解锁后旋转，右键平移；默认锁定角度、升降、缩放及第一人称恢复规则保留。

普通面框选以起始命中面确定列范围，每列沿面法线选择最外侧一个具有非空 OUTLINE 的方块。终点命中实际块时取其两轴切向坐标，避免高台/低谷投影偏移；空处回退固定面求交，V 模式仍固定面求交。上表面跟随最上层高度，下表面取最下层；墙面在锚点前后各 32 格的公共连续已加载窗口内取对应外侧。参考矩形保持起始平面，蓝色实际表面预览分帧显示；不选择整列内部，也不按屏幕像素采样。

松开左键重新创建表面作业并冻结墙面搜索窗口，查询当前世界，不将可能已被埋住或移除的旧预览直接提交。搜索窗口与区块依赖冻结后若卸载则整体拒绝，范围本身未加载也拒绝；真实加载核验使用 `level.getChunkSource().hasChunk`。普通范围最多 8192 列，已选集合最多 8192 成员，表面扫描每帧最多 2048 项/约 2 ms。V 固定底面加滚轮高度继续使用 8192 格范围和 256 格/约 2 ms 扫描预算，仍选择所有非空气成员，不采用普通表面的空 OUTLINE 过滤；G、Delete 及取消规则保留。
