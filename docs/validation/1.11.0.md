## 客户端待验收

1. 投影菜单打开“立体方块筛选”，搜索石头、原木等并多选后确认，再进行立体选择；非匹配方块与空气不进入选区。不同朝向同一类型应匹配；空筛选恢复全选，追加/右键清空、缩放和高度输入不穿透弹窗。
2. 清扫按键无选区也可打开方式弹窗。顶面清扫保持精确蓝色标记；按物品搜索选择多种类型后，下单时已加载殖民地范围内的实际可达匹配物品入仓。障碍、非匹配、他人所有和下单后新掉落不被收取；本批次完成后任务结束。满仓/暂停/休息不丢持料。
3. 人物详情 → 任务，开关五项工作并观察实际派工；关闭的空手工人不领对应活。带着原工程材料关闭任务后仍交付，之后停止领新料，全局工程优先度/FIFO保持。
4. 人物详情 → 装备，选择玩家实际物品栏中的工具/护甲，检查旧装备完整返回、新装备名称/附魔/耐久保持、原生护甲实际生效。主手持料不受影响；物品栏满、绑定诅咒、不适用槽位、跨所有权和物品已变化时明确拒绝且数量守恒。关闭自动取工具后不再去拿替代工具。
5. 右键住所，或殖民地 → 住所/人物页住所详情，检查合规原因、面积、床、当前住户；改名保存，指定住户不能抢占已住房间，自动入住关闭不驱逐已有住户，解除同时关闭自动入住。拆掉屋顶应立即显示不合规，无房仍能打印。
6. GUI 尺寸 320×180、480×270、640×360、窗口拖动/缩放、输入中文名称与搜索、Esc 返回、切换维度/退出重进、多人权限和大人口长期 TPS/FPS另做实机验收。不能以编译或服务端 GameTest 代替这些证据。
