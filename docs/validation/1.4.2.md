## 诊断与修复

用户提供的 219 项编辑器诊断包含 work 包和 WorkPanel 无法解析、空值安全问题及编辑器提示。项目与父工作区设置都把所有名为 work 的目录过滤掉，导致任务源码被 Java 索引忽略；现移除 Java 的 work 资源过滤，文件树仅隐藏工作区根目录的临时资料。

保留自动空值分析与 JSR-305 配置。用当前 Red Hat Java 扩展同版本 ECJ 3.46.100 复现并修复方法引用接收者、API 返回值、测试工厂与可空方块实体处理；空值脚本从 91 个主代码/JUnit 文件扩展至 95 个主代码/JUnit/GameTest 文件。库存事务的 matches 校验存在真实调用并保留，不能因类型解析失败产生的连带诊断删掉它。鼠标拖动分支改为 switch，中键旋转、右键平移、左键框选的调用条件保持一致。
