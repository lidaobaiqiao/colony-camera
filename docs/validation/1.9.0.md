# 1.9.0 验证记录

日期：2026-10-07。Minecraft 1.20.1 / Forge 47.4.0 / Java 17。

## 范围与兼容

落实最新版 0024 的状态层：八项基础属性、十项职业属性，无上限点数与对应有效工作/主动学习；六层十六职业框架包含能力路由、独立即时加成和成长加速。新增实际住所、学堂、食物/休息轮换、可视压力及罢工、忠诚和玩家特殊指令。

工匠精品工具、研究员研究加速、教师同堂教学已被生产/学习模块消费；整树、农艺、矿脉揭示、脚手架、高级机器、医疗、艺术产出和独立战斗 AI 的具体行为尚未实现，人物页区分“已接入”与“待独立模块”。0024 第九、十、十一节要求这些独立模块的状态接口，本版没有把职业标签当作完整行为。实施选择记录在 [0026](../decisions/0026-worker-state-first-implementation.md)，0025 编号继续留给后续任务调度设计。

工人 `ColonyState` schema 1、设施 `Living` schema 1；附加任务 SavedData schema 1–3 迁移为 4，保留制造/研究的有效工作进度。未知版本、未知字段和损坏的新工人/设施数据原样保留并停止相关操作。旧工人仅在迁移时读取旧挖掘经验，保留持料、真实工具、归属及历史计数；新成长不再读取那套阈值。工作网络协议 2，双方安装同版。升级前备份世界，回退必须恢复升级前备份。

## 真实服务器场景

新增十四项服务端回归，保留原 92 项：

- 工人属性、出生配置、压力、学习进度、193 件真实持料及任务归属读档保持；未知版本、同版本未来字段和非法双学位意图原样只读保留。
- 房间必须由实际地板、屋顶、边界、完整单床构成；缺住所拒绝打印、独立房间允许打印、重复标记不增加人口，拆除屋顶/床不会删除工人。
- 疲惫工人实际打开关闭的卧室木门，走到认领的床上入睡并恢复休息；Forge 交互保护拒绝时，尝试被事件实际拦截、门保持关闭、工人未入睡，住所认领保留。
- 学堂硬门槛、兴趣/属性软代价、双职业成长保留与在学压力；两名工人有各自住房、在同一学堂实际学习，教师停学后加成停止。
- 压力满时停止调度，恢复后续作；保留运输持料。饥饿工人吃掉真实归属面包，不替换施工材料。
- 十八项映射到实际动作；实体台阶高度和导航范围变化，感知影响观察者及被观察者，环境抗性减轻真实伤害并训练对应属性。建造工未练习也立即缩短施工动作。
- 工匠用三木板、二木棍制造一件实际带耐久增益的木镐，产物与原料守恒，工艺精度和操作效率的有效工作增长。
- 玩家处决请求验证忠诚，真实接近和伤害后才生效；隔墙工人不收到目击/转述。献身成功/失败给予不同且会过期的士气，不虚构扣血。
- 一次从真实仓储领取 80 件材料并建完 80 格，峰值持料 80、余料 48、完工持料 0，对应施工/搬运成长发生。此场景发现并修复工人身体仍与待建形状重叠时被宽松到站距离提前停止的错误。
- 低优先工程不能接管未完成高优先工程的持料，同级按创建时间优先；合成中罢工、恢复与读档保持实际累计工作，再准确产出一件工具。

256 块石体、三名初始石镐工人的最终基准为 **1133 tick，总移动 20.558 格**；真实挖掘历史、掉落和工具磨损各 256，目标独占断言成立。此版本不再随着破坏块数即时享受旧 MiningSkill 阈值加速，不能将这个新初始能力场景与 1.8.1 的 908 tick 当作同一成长规则下的速度对比。该测量是服务端游戏 tick 对照，不是客户端 FPS 或长期原世界 TPS 的承诺。

可复现最终服务端命令（先配置 Java 17，使用一个新测试世界）：

```powershell
./gradlew.bat test verifyArchitecture runGameTestServer --offline -Dnet.minecraftforge.gradle.check.certs=false -PgameTestWorld=world-v190-reproduction
```

环境探测参数仅对离线构建进程生效，没有写入全局配置。所有测试世界都在 `build/game-test-run`，未修改玩家世界。
